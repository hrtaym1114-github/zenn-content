# 公式ドキュメントが約束していること・いないこと

腐りの影響範囲は「いつ・何が読み込まれるか」で決まります。2026-10-20 時点の公式ドキュメントから、運用に効く点だけ抜き出します。仕様は変わるので、使う前に原文を確認してください。

## Claude Code（CLAUDE.md）

出典: [How Claude remembers your project](https://code.claude.com/docs/en/memory)、[Hooks reference](https://code.claude.com/docs/en/hooks)（いずれも 2026-10-20 参照）

- CLAUDE.md はセッション開始時に読み込まれ、複数あれば広いスコープから順に連結される（上書きではない）
- Claude は CLAUDE.md を「文脈」として扱い、強制される設定ではない。必ず止めたい操作は PreToolUse フックを使う、と明記されている
- v2.1.277 以降、CLAUDE.md がない場合は AGENTS.md を代わりに読む。両方読むには設定（Project instructions）が要る
- `paths:` 付きの rules やサブディレクトリの CLAUDE.md は、該当ファイルを読んだときに読み込まれる。圧縮（compaction）後にルートの CLAUDE.md は読み直されるが、これらは再び該当ファイルに触れるまで戻らない
- `/doctor prompt-audit`（v2.1.283 以降）で、古いモデル向けの書き方、存在しないファイルやコマンドへの参照、ファイル間の矛盾を Claude に点検させられる。結果は報告と差分の提案で、頼むまでファイルは変わらない

**運用上の含意**: 腐った1行は「毎セッション」効く。そして「絶対守らせたいこと」を CLAUDE.md に書いても、公式には守られる保証がない。守らせたいことは hooks に寄せる（章06）。

## Codex（AGENTS.md）

出典: [Custom instructions with AGENTS.md](https://developers.openai.com/codex/guides/agents-md)（2026-10-20 参照）

- グローバル（`~/.codex`）→ プロジェクトルートから作業ディレクトリまで、各ディレクトリ1ファイルずつ連結。近いものほど後に来て優先される
- `AGENTS.override.md` やフォールバック名（`project_doc_fallback_filenames`）を設定できる
- 合計サイズが上限（`project_doc_max_bytes`、既定 32 KiB）に達すると、それ以降は読み込まれない

**運用上の含意**: 使われない記述や重複は、ただの無駄ではなく「後ろの指示が切り捨てられる」原因になりうる。

## 公式が約束していないこと

どちらも、指示ファイルを**読み込むときに**参照の実在を検査してはくれません。存在しないパスやコマンドが書かれていても、読み込みはエラーにも警告にもなりません。

Claude Code の `/doctor prompt-audit` は、頼めば点検してくれる仕組みです。ただし LLM による点検なので、毎回同じ範囲を同じように見る保証はありません。費用と時間もかかります（章02の実測では1ファイルで約139秒）。編集のたびに機械的に確かめる部分は、利用者側の運用で埋めることになります。
