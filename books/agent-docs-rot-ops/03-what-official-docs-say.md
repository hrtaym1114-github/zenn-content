# 公式ドキュメントが約束していること・いないこと

腐りの影響範囲は「いつ・何が読み込まれるか」で決まります。2026-10-12 時点の公式ドキュメントから、運用に効く点だけ抜き出します。仕様は変わるので、使う前に原文を確認してください。

## Claude Code（CLAUDE.md）

出典: [How Claude remembers your project](https://code.claude.com/docs/en/memory)、[Glossary](https://code.claude.com/docs/en/glossary)、[Context window](https://code.claude.com/docs/en/context-window)（いずれも 2026-10-12 参照）

- CLAUDE.md はセッション開始時に読み込まれ、複数あれば広いスコープから順に連結される（上書きではない）
- Claude は CLAUDE.md を「文脈」として扱い、強制される設定ではない。必ず止めたい操作は PreToolUse フックを使う、と明記されている
- 一定バージョン以降、CLAUDE.md がない場合は AGENTS.md を代わりに読む。両方読むには設定が要る
- `paths:` 付きの rules やサブディレクトリの CLAUDE.md は、該当ファイルを読んだときに読み込まれ、圧縮（compaction）後は要約に溶ける

**運用上の含意**: 腐った1行は「毎セッション」効く。そして「絶対守らせたいこと」を CLAUDE.md に書くのは、公式にも保証されていない。守らせたいことは hooks に寄せる（章06）。

## Codex（AGENTS.md）

出典: [Custom instructions with AGENTS.md](https://developers.openai.com/codex/guides/agents-md)（2026-10-12 参照）

- グローバル（`~/.codex`）→ プロジェクトルートから作業ディレクトリまで、各ディレクトリ1ファイルずつ連結。近いものほど後に来て優先される
- `AGENTS.override.md` やフォールバック名を設定できる
- 合計サイズが上限（既定 32 KiB）に達すると、それ以降は読み込まれない

**運用上の含意**: 使われない記述や重複は、ただの無駄ではなく「後ろの指示が切り捨てられる」原因になりうる。

## 公式が約束していないこと

どちらのドキュメントも、**指示ファイル内の参照が実在するか** は検査しません。存在しないパスやコマンドが書かれていても、エラーにも警告にもなりません。ここを埋めるのが、利用者側の運用です。
