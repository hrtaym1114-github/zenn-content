# チェックリスト

コピーして、自分のリポジトリの rules やイシューテンプレートに貼ってください。

## 書くとき

- [ ] モデル名・プラン名・件数・残量を書いていない（書くなら正本の場所と確認コマンド）
- [ ] パスはリポジトリルート基準、またはスキル内なら `./` から始めている
- [ ] プレースホルダは実在パスと見分けがつく記法（`<...>`）
- [ ] スラッシュコマンドは実際の呼び方（名前空間つきならそのまま）
- [ ] 「絶対に守らせたいこと」は指示ファイルではなく hooks にある

## 改名・削除するとき

- [ ] 旧名で CLAUDE.md / AGENTS.md / `.claude/` / `.agents/` を検索した
- [ ] 置き換え先の名前に **実体のファイル** がある（新しい名前に揃えただけで終わっていない）
- [ ] 使わなくなったエージェント・スキルはアーカイブへ移した
- [ ] 雛形はエージェント定義の置き場所に混ぜていない

## 二重管理

- [ ] Claude Code 用と Codex 用のどちらが正本か決めている
- [ ] もう片方は生成物で、手で編集していない
- [ ] CLAUDE.md と AGENTS.md に同じ方針を二重に書いていない（片方から参照）

## 静的チェック

- [ ] プレースホルダ・出力先ディレクトリを除外設定に入れた
- [ ] 指示ファイルの外から呼ばれる定義（スケジューラ・CI）を許可リストに入れた
- [ ] 現状の警告をベースラインとして保存し、新規だけを CI で落としている
- [ ] 警告数を「腐りの数」と読んでいない

## 監査するとき

- [ ] 外部ツールのオプション値・仕様を実機で確かめた（静的チェックでは拾えない）
- [ ] 差分は人間がレビューしてからコミットした
- [ ] 監査の内訳（何が何件）を記録に残した
