# 第1章: ChatGPTだけじゃない --- 2026年AI仕事術の新常識

月曜の朝、あなたはメールの山を前にしています。クライアントへの提案書を仕上げなければならず、先週の会議の議事録もまだ手つかず。隣の席の同僚は、ChatGPTを使って30分で企画書を仕上げたと話しています。「自分もAIを使いこなさないと」。そう思いながらも、どこから手をつければいいのか分からない。

あるいは、あなたはすでにChatGPTを使いこなしている方かもしれません。でも、長い報告書を読み込ませると途中で要約が雑になる。ビジネスメールを書かせると、どこか「AIっぽい」文章になる。「もう少し自分の仕事に合った使い方ができないものか」と感じている。

どちらの方にも、この本でお伝えしたいことがあります。**ChatGPTだけがAIの選択肢ではありません。** そして、あなたの仕事の内容によっては、別のAIの方がずっと相性が良い可能性があるのです。

この章では、2026年の生成AI活用の現在地を確認したうえで、ChatGPTとClaudeを率直に比較します。「乗り換え」を勧めるつもりはありません。あなたの仕事にとって、どちらがどう役立つのか。その見極め方をお伝えします。


## 1.1 生成AI仕事術の現在地 --- 「使えるけど使いこなせない」時代

2025年には、日本企業の過半数が何らかの形でAIを導入しているとされています。しかし、数字だけを見て「もうAIは普及した」と判断するのは早計です。

現場の声に耳を傾けると、まったく別の景色が見えてきます。

- **「AIで何ができるか分からない」** --- 導入はしたが、ChatGPTの無料版を時々触る程度
- **「自社ビジネスへの活かし方が不明」** --- 一般的な質問はできるが、自分の業務に直結する使い方が見えない
- **「使える人と使えない人の差が開いている」** --- 一部の詳しい社員だけが活用し、ノウハウが属人化している

みずほフィナンシャルグループやクラスメソッドをはじめ、メルカリ、パナソニック、日立製作所、NECなど、名だたる企業が生成AIの導入を進めています（具体的な導入事例は第11章で詳しく紹介します）。

一方で、多くのビジネスパーソンは「AIを使っている」と言いながら、実際には表面的な使い方にとどまっています。ここに**AI格差**が生まれています。使いこなせる人は仕事の質とスピードを劇的に高め、そうでない人は従来のやり方を続けている。この差は、2026年以降さらに広がっていくでしょう。

:::message
**AI格差は「ツール選び」から始まる**: 自分の業務に合ったAIを選び、正しい使い方を身につけること。これがAI格差を埋める最初の一歩です。本書は、その一歩を具体的にサポートします。
:::

この本を手に取ったあなたは、すでにその一歩を踏み出しています。大切なのは、「とりあえずChatGPT」で止まるのではなく、自分の仕事に本当にフィットするAIを知ることです。


## 1.2 ChatGPT vs Claude --- 率直な比較

「ChatGPTとClaude、何が違うの？」

これは最もよく聞かれる質問です。結論から言えば、**どちらが上かではなく、何に使うかで選ぶ**のが正解です。それぞれに明確な得意分野があります。

### 日本語の文章品質

ビジネスパーソンにとって、最も気になるポイントの1つがこれでしょう。

Claudeの日本語は、**表現の丁寧さと語尾変化の豊かさ**に定評があります。「です・ます」の単調な繰り返しを避け、「でしょう」「かもしれません」「と言えます」など、語尾を自然に変化させます。ビジネス文書やフォーマルなレポートを書かせたとき、この品質の差は顕著に現れます。指示されたトーンや制約を厳密に守る傾向があるため、「丁寧に」「カジュアルに」といった指定が的確に反映されます。

一方、ChatGPTの日本語は**自然さと滑らかさ**が特徴です。主語の省略や接続詞の使い方が日本語の文章作法に沿っており、読んでいて引っかかりが少ない文章を生成します。

どちらが良いかは用途次第です。公式な報告書やプレスリリースなど「きちんとした文書」にはClaudeの丁寧さが活き、社内のカジュアルなやり取りや読み物コンテンツにはChatGPTの滑らかさが合う場面もあるでしょう。

### 長文ドキュメントの処理

ビジネスの現場では、数十ページの報告書、契約書、研究資料を扱うことが日常的にあります。ここに、両者の設計思想の違いが現れます。

Claudeのコンテキストウィンドウ（一度に読み込める情報量）は**200Kトークン**です。英語で約500ページの書籍に相当します。日本語はトークン消費が英語より大きいため実質的にはやや少なくなりますが、それでも相当な分量です。

ChatGPTの最新モデル（GPT-5.2）は**400Kトークン**と、数字の上ではClaudeの2倍です。

しかし、ここで重要なのは「量」だけではありません。Claudeは**長い文書の全体にわたって推論の品質を維持する**と評価されています。つまり、500ページの資料を読み込ませたとき、冒頭の情報も末尾の情報も同じ精度で扱えるということです。コンテキストウィンドウの大きさだけでなく、その「使い方の質」に違いがあるのです。

実務でいえば、100ページの契約書のリスク分析や、複数の長文レポートの横断比較といった作業では、この「品質維持」の差が成果物の信頼性に直結します。

### 安全性とコンプライアンス

Claudeを開発しているAnthropic社は、**Constitutional AI**（憲法的AI）という独自のアプローチを採用しています。これは、AIの振る舞いを一連の原則に基づいて制御する仕組みです。

企業にとってのメリットは明確です。コンプライアンスを重視する組織、金融・法務・医療など慎重さが求められる業界では、AIの「暴走」リスクが最小限であることが導入の前提条件になります。Claudeはハルシネーション（もっともらしい嘘）が比較的少ないと評価されており、この点も企業導入の後押しになっています。

### マルチモーダル機能

ここは率直に言って、**ChatGPTが大きくリードしている領域**です。

ChatGPTはDALL-E統合による画像生成、Advanced Voice Mode（音声会話）、動画の理解など、テキスト以外の入出力に幅広く対応しています。「この写真の内容を説明して」「プレゼン用の画像を作って」「英語の発音を練習したい」。こうした要望には、ChatGPTが適しています。

Claudeは2026年2月時点で画像生成と音声会話に対応していません。テキストと画像の読み取り（入力としての画像理解）は可能ですが、画像を「作る」ことはできません。

### 料金

料金体系は驚くほど似ています。

| プラン | Claude | ChatGPT |
|--------|--------|---------|
| 無料 | あり（基本機能） | あり（GPT-4o制限付き） |
| 個人有料（標準） | Pro $20/月 | Plus $20/月 |
| 個人有料（上位） | Max $100/月 or $200/月 | Pro $200/月 |
| チーム | 年払い$25/月、月払い$30/月 | $25/月/人 |
| エンタープライズ | カスタム価格 | カスタム価格 |

個人利用なら月額$20（約3,000円）でスタートできる点は同じです。**選択基準は料金ではなく、機能と品質で決まります。**

### 主要機能の対比

両者はそれぞれ独自の機能を進化させています。本書で詳しく解説するClaudeの3つの主力機能を中心に、対応するChatGPTの機能と並べてみましょう。

| カテゴリ | Claude | ChatGPT |
|---------|--------|---------|
| 知識管理 | **Projects** | GPTs / Memory |
| 成果物生成 | **Artifacts** | Canvas |
| デスクトップ自動化 | **Cowork** | ChatGPT agent |
| Excel統合 | Claude in Excel | Copilot in Excel |
| 画像生成 | 非対応 | DALL-E統合 |
| 音声会話 | 非対応 | Advanced Voice Mode |

**Projects**は、業務資料をまるごとClaudeに読み込ませ、「あなたの会社を知っているAI」を作る機能です（第3章で詳しく解説します）。**Artifacts**は、チャットの中で完成形の文書やフローチャート、Webツールを直接生成する機能です（第4章で詳しく解説します）。**Cowork**は、デスクトップ上のファイル操作やタスクをAIに任せるエージェント機能です（第12章で紹介します）。

これら3つの機能は、ChatGPTのGPTs・Canvas・ChatGPT agentとそれぞれ対応していますが、設計思想が異なります。Claudeの機能群は「長文の理解力」と「正確な指示遵守」を土台にしており、特にビジネス文書の作成や大量資料の分析といった業務で強みを発揮します。


## 1.3 「使い分け」の結論 --- こういう仕事にはClaude

比較を踏まえたうえで、結論はシンプルです。

**画像を作りたい、音声で対話したい → ChatGPT。文章を書きたい、長文を分析したい、業務に特化したAIを作りたい → Claude。**

もう少し具体的に整理しましょう。

```
Claudeが向いている仕事          ChatGPTが向いている仕事
─────────────────────          ─────────────────────
長い報告書・契約書の分析          プレゼン用の画像生成
フォーマルなビジネス文書の作成    ブレインストーミング（創造性重視）
自社資料に基づく回答生成          音声での対話・言語学習
コンプライアンス重視の業務        プラグインを活用した連携
複雑な推論が必要な分析            マルチモーダルな作業全般
```

もちろん、どちらか一方しか使ってはいけないわけではありません。両方を契約している方も少なくないでしょう。大切なのは、**「今やろうとしている仕事にはどちらが合っているか」を判断できること**です。

この本では、上の表の左側 --- Claudeが特に活きる業務領域にフォーカスして、具体的なワークフローをお伝えしていきます。


## 1.4 Claudeが特に活きる業務5選

それでは、Claudeの強みが最も発揮される5つの業務領域を紹介します。コミュニティや企業での活用事例をもとにまとめたものです。

### 1. 法務・コンプライアンス

契約書のレビュー、リスク条項の抽出、判例の調査。法務の仕事は、長文を正確に読み解き、細部の矛盾や見落としを指摘する能力が求められます。Claudeの「長文を品質維持して処理する力」と「ハルシネーションの少なさ」は、この領域で大きな信頼を得ています。

Projectsに契約書テンプレートと社内規程を登録しておけば、新しい契約書をアップロードするだけで「自社基準に照らしたリスク分析」を瞬時に実行できます。

### 2. 高品質な文章作成

プレスリリース、公式レポート、提案書、社外向けの文書。トーンの統一性と表現の正確さが求められる文章作成は、Claudeの得意分野です。「フォーマルに書いて」「この読者層に合わせて」といった指示を忠実に守るため、校正の手間が大幅に減ります。

Artifactsを使えば、チャットの中で文書の完成形を確認しながら「ここをもう少し具体的に」「トーンを柔らかく」と修正を重ねることもできます。

### 3. 長文ドキュメントの分析

50ページの調査レポート、100ページの技術文書、数百ページの論文。「全体を読んだうえで要点を3つ挙げて」「5つの資料に共通するトレンドを見つけて」。こうした横断的な分析は、200Kトークンのコンテキストウィンドウを効果的に使えるClaudeの真骨頂です。

Projectsにナレッジとして蓄積すれば、過去の調査結果を踏まえた新しい分析も可能になります。

### 4. 人事・採用

職務経歴書や面接記録の分析、評価レポートの作成、研修資料の整備。人事の仕事は、多くのテキスト情報を公平に読み解く必要があります。Claudeの安全性への配慮と、長文処理の正確さが評価されている領域です。

### 5. 顧客サポート

長い問い合わせ履歴を把握したうえで、文脈に沿った丁寧な回答を生成する。過去のやり取りを全て読み込んだうえで「この顧客の懸念点は何か」を正確に把握するClaudeの能力は、サポート業務の品質を底上げします。

:::message
**5つすべてに共通する特徴**: 「長い文書を正確に読み解く」「指示通りのトーンで文章を生成する」「慎重さが求められる」。この3つが揃う業務では、Claudeが特に力を発揮します。
:::


## 1.5 この本が向いている人 / 向いていない人

最後に、この本の対象読者を明確にしておきましょう。期待と内容のミスマッチは、お互いにとって不幸です。

### この本が向いている人

- **ChatGPTは使ったことがあるが、Claudeは初めて**という方。両者の違いを理解し、Claudeの使い方を基礎から学べます
- **AIを仕事に取り入れたいが、具体的な方法が分からない**という方。業務別のワークフローを1つずつ実践できます
- **チームにAIを導入したいが、セキュリティが不安**という方。第11章でガバナンスと段階的な展開方法を扱います
- **すでにClaudeを使っているが、Projectsを活用できていない**という方。第3章以降で、「普通に使う」から「業務に特化させる」への飛躍をサポートします

### この本が向いていない人

- **プログラミングの教科書を探している方**。本書はビジネスパーソン向けで、コードを書くことを前提としていません
- **画像生成やマルチモーダルAI活用を学びたい方**。これらはChatGPTの方が適しており、本書のスコープ外です
- **AIの技術的な仕組み（トランスフォーマー、LLM等）を深く理解したい方**。本書は「使い方」に徹しています

本書の全13章を通じて、あなたはClaudeを「たまに質問するAI」から「毎日の仕事を支える相棒」へと変えることができます。Projects、Artifacts、プロンプトの5原則、そして業務別ワークフロー。すべて実践的で、読んだその日から使えるものです。


## 1.6 まとめ

この章のポイントを整理します。

- **AI格差が広がっている**: 過半数の企業がAIを導入する中、「使いこなせない」壁に直面するビジネスパーソンは多い
- **ChatGPTとClaudeは「使い分け」が正解**: どちらが上かではなく、仕事の内容に応じて選ぶ
- **Claudeの3つの強み**: 日本語文章の品質、長文処理の正確さ、安全性とコンプライアンスへの配慮
- **ChatGPTの強み**: 画像生成、音声対話、マルチモーダル機能の充実
- **Claudeが特に活きる業務**: 法務、文章作成、長文分析、人事、顧客サポート --- 「長文 + 正確さ + 慎重さ」が求められる仕事
- **料金は同等（$20/月）**: 選択基準は機能と品質で決まる
