# 第2章: 5分で始めるClaude Pro --- セットアップと基本操作

前章で、Claudeがどんな仕事に向いているかをお伝えしました。ここからは、実際に手を動かしていきましょう。この章を読み終える頃には、あなたはClaudeとの最初の会話を終えているはずです。

「セットアップ」と聞くと身構えるかもしれませんが、心配はいりません。Claudeのアカウント作成は、Webサービスの会員登録と同じくらいシンプルです。特別なソフトウェアのインストールも、クレジットカードの登録も（無料プランなら）不要です。


## 2.1 アカウントを作成する

まず、Claudeのアカウントを作りましょう。以下の3つの方法から選べます。

1. **メールアドレスで登録** --- 仕事用メールで登録すれば、後からTeamプランに移行する際もスムーズです
2. **Googleアカウントで登録** --- Google Workspaceを使っている方はこれが最も手軽です
3. **Apple IDで登録** --- iPhoneやMacをお使いの方はこちらも便利です

### 登録手順（所要時間: 約2分）

```
Step 1: https://claude.ai にアクセス
Step 2: 「Sign up」をクリック
Step 3: メール / Google / Apple ID のいずれかを選択
Step 4: メール認証（メール登録の場合）
Step 5: 利用規約に同意
```

これだけです。登録が完了すると、すぐにチャット画面が表示されます。

:::message
**仕事用メールでの登録を推奨します**: 将来、チームでの利用に移行する可能性を考えると、会社のメールアドレスで登録しておくのが無難です。個人のGmailで始めてしまうと、後からTeamプランに合流する際に別アカウントが必要になることがあります。
:::

### デスクトップアプリとモバイルアプリ

Claudeはブラウザだけでなく、専用アプリでも利用できます。

| 環境 | 入手方法 |
|------|---------|
| Web（推奨） | https://claude.ai にアクセス |
| macOS | App Store または claude.ai/download |
| Windows | claude.ai/download |
| iOS | App Store で「Claude」を検索 |
| Android | Google Play で「Claude」を検索 |

最初はブラウザ版（claude.ai）で始めるのがおすすめです。アプリ版はほぼ同じ機能を備えていますが、ブラウザ版の方が画面が広く、Artifactsの表示も見やすいためです。慣れてきたら、移動中にモバイルアプリを使う、デスクトップアプリをショートカットキーで呼び出す、といった使い分けも良いでしょう。


## 2.2 Free / Pro / Team --- どのプランを選ぶべきか

アカウントを作成した時点では、Freeプラン（無料）が適用されています。まずはこのまま使い始めて構いません。ただし、本書のワークフローを本格的に実践するなら、**Proプラン**への移行をおすすめします。

### プラン比較

| | Free | Pro（推奨） | Team |
|---|---|---|---|
| 月額 | $0 | $20（約3,000円） | 年払い$25/月、月払い$30/月 |
| メッセージ量 | 制限あり | Freeの大幅増量 | Proと同等+ |
| Projects | 最大5つ | 無制限 | 無制限+共有 |
| Artifacts | 利用可 | 利用可 | 利用可 |
| Extended Thinking | 不可 | 利用可 | 利用可 |
| Research | 不可 | 利用可 | 利用可 |
| Claude in Excel | 不可 | 利用可（ベータ） | 利用可（ベータ） |
| SSO/管理機能 | 不可 | 不可 | 利用可 |
| 最低人数 | --- | --- | 5名 |

### Freeプランでできること

Freeプランは「お試し」以上の実力があります。基本的なチャット、コード生成、テキスト分析、画像の読み取りに加え、**Projectsも5つまで作成可能**、**Artifactsも利用可能**です。「Claudeがどんなものか試してみたい」という段階なら、Freeプランで十分に体験できます。

ただし、メッセージ数に制限があります。具体的な上限は公開されておらず、利用状況に応じて変動しますが、仕事で本格的に使い始めると1日で上限に達することも珍しくありません。

### Proプランを推奨する3つの理由

**理由1: 核心機能が解放される**

Proプランで使えるようになる機能の中でも、特にビジネスで重要なのが以下の3つです。

- **Extended Thinking（拡張思考モード）**: Claudeが回答の前に「じっくり考える」モード。複雑な分析や戦略立案で、回答の質が格段に上がります
- **Research（Web検索で最新情報を取得する機能）**: Claudeがインターネット上の最新情報を検索して回答に反映する機能。市場調査や競合分析に不可欠です
- **無制限のProjects**: Freeの5つでは、業務ごとにProjectを分ける運用がすぐに限界を迎えます

**理由2: 月3,000円の投資対効果**

月額$20は日本円で約3,000円です。これを「高い」と感じるか「安い」と感じるかは、どう使うかで決まります。

1つの具体例を挙げましょう。毎朝のメール返信に30分かかっていたとします。Claudeを使えば、下書き生成で10分に短縮できるケースは珍しくありません。1日20分の節約 x 20営業日 = 月に約6.5時間の節約。あなたの時給が2,000円なら、それだけで13,000円分の価値です。月3,000円の投資で13,000円分の時間が生まれる計算になります。

**理由3: 年払いでさらにお得**

年払いを選ぶと月額が割引になります。すでにClaudeを気に入っていて、継続利用が確実なら、年払いへの切り替えも検討してください。

:::message
**まずはFreeで試し、1週間以内にProへ**: Freeプランで数日使ってみて「これは仕事に使える」と実感できたら、Proに切り替えましょう。本書の第3章以降のワークフローは、Proプランの機能を前提に解説しています。
:::

### Teamプランはいつ必要か

Teamプランは、チームでの導入を検討している管理者向けです。年払いで1人あたり$25/月（月払いでは$30/月）、最低5名から契約できます。SSO（シングルサインオン）、管理者によるメンバー管理、プロジェクトの共有機能が追加されます。

個人で始めるなら、まずはProプランで十分です。チーム導入については第11章で詳しく解説しますので、管理者の方はそちらも参考にしてください。

### Maxプランについて

Proプランの5倍（$100/月）または20倍（$200/月）の使用量を提供するパワーユーザー向けプランです。**Cowork**（macOSデスクトップエージェント）など追加機能も利用できます。一般的なビジネス利用であれば、まずProで始めて、使用量の上限に頻繁に達するようになったらMaxへの移行を検討する、という順序で問題ありません。


## 2.3 Proプランへのアップグレード手順

Proプランへの移行も簡単です。

```
Step 1: claude.ai にログイン
Step 2: 画面左下のアカウント名をクリック
Step 3: 「Upgrade to Pro」または「Settings」→「Billing」を選択
Step 4: 支払い情報を入力（クレジットカード）
Step 5: プランを確認して「Subscribe」をクリック
```

支払いはクレジットカードのみです。日本発行のVisa、Mastercard、JCB、American Expressが利用できます。請求はドル建てで、カード会社の為替レートが適用されます。


## 2.4 基本画面を知る

ログインすると、Claudeのメイン画面が表示されます。まず、画面の構成を把握しましょう。

```
+---------------------------------------------------+
|  [三] サイドバー      Claude            [設定][?]  |
+----------+----------------------------------------+
|          |                                        |
| 会話     |        チャット画面                      |
| 履歴     |                                        |
|          |     「How can I help you today?」       |
| --------+|                                        |
|          |                                        |
| Projects |                                        |
|          |                                        |
|          +----------------------------------------+
|          | [メッセージ入力欄]           [送信 ↑]   |
+----------+----------------------------------------+
```

### サイドバー（左側）

- **会話履歴**: 過去のチャットが時系列で並びます。クリックすれば、いつでも過去の会話に戻れます
- **Projects**: 業務テーマごとにチャットや資料をまとめる機能（第3章で詳しく解説）
- **新規チャット**: サイドバー上部の「New chat」ボタンで、新しい会話を始められます

### チャット画面（中央）

ここがClaudeとの対話の場です。あなたがメッセージを送ると、Claudeの回答がここに表示されます。テキストだけでなく、表、コードブロック、Mermaid図なども表示されます。

### メッセージ入力欄（下部）

テキストを入力して送信するエリアです。いくつかのポイントを押さえておきましょう。

- **Enterキー**: メッセージを送信します
- **Shift + Enter**: 改行します（送信せずに次の行へ）
- **ファイル添付**: クリップアイコンから、PDF・画像・テキストファイルなどを添付できます
- **モデル選択**: 入力欄の近くにあるモデル選択から、使用するモデル（Sonnet、Haiku、Opusなど）を切り替えられます

:::message
**Shift + Enter を覚えておきましょう**: 長い指示を送るとき、改行なしの1文にまとめると読みにくくなります。適度に改行を入れることで、Claudeもあなたの意図を正確に理解しやすくなります。
:::


## 2.5 最初の会話 --- Claudeに自己紹介してもらう

準備が整いました。さっそくClaudeと話してみましょう。

最初の会話として、こんなメッセージを送ってみてください。

```
こんにちは。私は[あなたの名前]です。
[職種や業界]の仕事をしています。

あなたのことを教えてください。
- どんなことが得意ですか？
- 私の仕事でどう役立てそうですか？
```

たとえば、こんな感じです。

```
こんにちは。私は田中です。
メーカーの営業企画部で、提案書の作成や市場分析を担当しています。

あなたのことを教えてください。
- どんなことが得意ですか？
- 私の仕事でどう役立てそうですか？
```

Claudeは、あなたの職種に合わせた具体的な活用例を提案してくれるはずです。「提案書のドラフト作成」「競合他社の分析」「プレゼン資料の構成案」など、あなたの業務に即した提案が返ってくるでしょう。

### なぜ最初に自己紹介するのか

Claudeは会話の文脈を理解して回答を調整します。最初に「自分は誰で、どんな仕事をしているか」を伝えることで、以降の回答があなたの状況に合ったものになります。

ただし注意点が1つあります。**Claudeは会話をまたいで情報を記憶しません。** 新しいチャットを始めると、前回の会話内容はリセットされます。「毎回自己紹介するのは面倒だ」と感じたら、それこそがProjectsの出番です（第3章で解説します）。


## 2.6 日本語で使いこなすコツ

Claudeは日本語に高い対応力を持っています。ただし、いくつかのコツを知っておくと、回答の質がさらに上がります。

### コツ1: 箇条書きで指示する

長い文章で指示するよりも、箇条書きで要点を分けた方がClaudeは正確に理解します。

```
悪い例:
来週のチーム会議で使うプレゼン資料の構成案を考えてほしいのですが、
テーマは今期の営業成績の振り返りで、10分程度で発表する想定で、
スライドは10枚以内にまとめたいです。

良い例:
以下の条件でプレゼン資料の構成案を作ってください。

- テーマ: 今期の営業成績の振り返り
- 発表時間: 10分
- スライド枚数: 10枚以内
- 聴衆: チームメンバー（10名）
- ゴール: 来期の改善点を共有する
```

### コツ2: 「誰に向けた」「何のための」を明示する

Claudeに文章を書かせるとき、「読む人」と「目的」を伝えると、トーンや内容が適切に調整されます。

```
「部長向けの週次報告メール」と指定すれば、フォーマルかつ簡潔な文面に。
「新入社員向けの業務マニュアル」と指定すれば、丁寧で分かりやすい文面に。
```

### コツ3: 出力のフォーマットを指定する

「表にして」「箇条書きで」「500字以内で」といったフォーマット指定は、Claudeが忠実に守る得意分野です。

```
以下の3つの案を比較する表を作ってください。
列: 案の名前、メリット、デメリット、コスト、実現可能性
```

このように指定すれば、きちんと整形された表が返ってきます。プロンプトの書き方については第6章でさらに詳しく掘り下げますが、まずはこの3つを意識するだけで、回答の質は大きく変わります。


## 2.7 プライバシーとデータの取り扱い

ビジネスでAIを使ううえで、「入力したデータがどう扱われるか」は避けて通れない問題です。Claudeのデータポリシーを確認しておきましょう。

### 学習利用について

デフォルトでは、Free / Proプランの会話内容がClaudeのモデル改善（学習）に利用される可能性があります。ただし、**オプトアウト（学習利用の停止）が可能**です。

### オプトアウトの設定手順

```
Step 1: claude.ai にログイン
Step 2: 画面左下のアカウント名をクリック → 「Settings」
Step 3: 「Privacy」セクションを探す
Step 4: 「Allow training on your data」のトグルをオフにする
Step 5: 設定を保存
```

:::message
**業務データを扱うなら、オプトアウト設定を推奨します**: 特に社外秘の情報や顧客データを入力する可能性がある場合は、初期設定としてオプトアウトをオンにしておきましょう。Teamプラン・Enterpriseプランでは、デフォルトで学習利用がオフになっています。
:::

### 何を入力してよいか --- 簡易チェックリスト

AIに入力するデータについて、以下を目安にしてください。

| 入力してOK | 注意が必要 | 入力を避ける |
|-----------|-----------|-------------|
| 一般的なビジネス文書の下書き | 社内の非公開情報 | 個人情報（氏名・住所・電話番号等） |
| 公開されている情報の分析 | 顧客企業の情報 | パスワード・認証情報 |
| 学習・調査目的の質問 | 未発表の製品・戦略情報 | 法的に守秘義務のある情報 |

「注意が必要」に分類される情報は、オプトアウト設定をしたうえで、社内のAI利用ポリシーに従って判断してください。自社にまだAI利用ポリシーがない場合は、第11章のチーム導入ガイドでテンプレートを紹介していますので、参考にしてください。


## 2.8 まとめ

この章のポイントを整理します。

- **アカウント作成は2分で完了**: メール、Google、Apple IDのいずれかで登録。仕事用メールがおすすめ
- **まずFreeで試し、Proへ移行**: Freeでも基本機能は使えるが、Extended Thinking・Research・無制限Projectsなど核心機能はProプランから
- **Proプランは月額$20（約3,000円）**: 1日の時短効果を考えれば、投資対効果は十分に高い
- **基本操作は3つ覚えるだけ**: メッセージ送信（Enter）、改行（Shift+Enter）、ファイル添付（クリップアイコン）
- **日本語のコツ**: 箇条書きで指示する、読者と目的を明示する、出力フォーマットを指定する
- **プライバシー設定を忘れずに**: 業務利用ならオプトアウト設定を推奨

ここまでで、Claudeを使い始める準備は整いました。次の章からは、Claudeの真価を引き出す機能に入っていきます。
