# 第3章: Projects --- あなた専用のAIアシスタントを作る

あなたの会社には、業務マニュアルや商品カタログ、就業規則、過去の提案書といった「自社の知識」が蓄積されているはずです。しかし、Claudeはそれらの存在を知りません。どんなに優秀なAIでも、あなたの会社のことを何も知らない状態では、一般的な回答しか返せないのです。

「うちの商品に合った提案書を書いて」と頼んでも、商品の仕様も価格も知らないClaudeには、当たり障りのないテンプレートを返すのが精一杯です。

この問題を解決するのが、**Projects**（プロジェクト）です。自社の資料をアップロードし、「あなたはこういう役割で回答してください」と指示を設定することで、Claudeを**あなたの業務に特化した専門AIアシスタント**に変えることができます。

この章では、Projectsの仕組みから作り方、そして4つの実践パターンまでを順番に見ていきます。


## 3.1 Projectsとは --- 「AIに予備知識を与える部屋」

Projectsを一言で表すなら、**「Claudeに予備知識を与える専用の部屋」**です。

たとえ話で考えてみましょう。あなたが新しく入社した社員に仕事を頼むとき、いきなり「提案書を書いて」とは言わないはずです。まず、商品カタログや過去の提案書を渡し、「うちではこういうトーンで書くんだよ」と教えるのではないでしょうか。

Projectsは、まさにこの「入社時の引き継ぎ」をClaudeに対して行う機能です。具体的には、次の2つの要素で構成されています。

1. **ナレッジベース（ファイルアップロード）**: 自社の資料をClaudeに読み込ませる
2. **カスタムインストラクション**: 「こういう役割で、こういうルールで回答して」と指示を設定する

この2つを組み合わせることで、Claudeは「あなたの会社の文脈を理解した専門AIアシスタント」になります。

```
┌─────────────────────────────────────────────┐
│  Project: 営業アシスタント                     │
│                                               │
│  ┌──────────────────────┐  ┌──────────────┐  │
│  │ ナレッジベース        │  │ カスタム      │  │
│  │ ・商品カタログ.pdf    │  │ インストラク  │  │
│  │ ・過去の提案書.docx   │  │ ション        │  │
│  │ ・価格表.xlsx         │  │              │  │
│  │ ・FAQ.pdf             │  │ 「ベテラン    │  │
│  └──────────────────────┘  │  営業として   │  │
│                            │  回答して」    │  │
│  ────────────────────────  └──────────────┘  │
│  ↓ この知識を踏まえて会話 ↓                    │
│  ┌──────────────────────────────────────┐     │
│  │  会話1: 提案書のドラフト作成         │     │
│  │  会話2: 顧客への質問回答            │     │
│  │  会話3: 競合との比較資料            │     │
│  └──────────────────────────────────────┘     │
└─────────────────────────────────────────────┘
```

通常のチャットでは、毎回ゼロから文脈を説明する必要があります。しかしProjectsを使えば、一度アップロードした資料と設定した指示が、そのプロジェクト内の**すべての会話に自動的に適用**されます。何度新しいチャットを開いても、Claudeは「あなたの会社のことを知っている状態」からスタートしてくれるのです。

:::message
**利用プラン**: Projectsはすべてのプランで利用できます（無料プランは最大5プロジェクトまで）。ただし、大量のドキュメントを効率的に検索・参照する拡張ナレッジ機能はPro（月額$20）以上のプランで利用できます。本書で紹介する実践パターンを十分に活用するには、Pro以上のプランをおすすめします。
:::


## 3.2 200Kトークンの実力 --- どれだけの資料を読み込めるか

Projectsに登録できる資料の総量は、**200Kトークン**（約20万トークン）です。これはClaudeのコンテキストウィンドウ（一度に読み込める情報量）と同じサイズで、Anthropic社は英語で**「500ページの書籍に相当する」**と説明しています。日本語テキストはトークン消費が英語より大きいため、日本語のみの場合は実質的にこれより少なくなりますが、業務資料を登録するには十分な容量です。

具体的にどのくらいかというと、次のような資料を登録できます。

| 資料の種類 | 目安の分量 |
|-----------|-----------|
| ビジネス書1冊（新書サイズ） | 丸ごと1冊 |
| 社内マニュアル | 200ページ分 |
| 契約書テンプレート | 50種類以上 |
| 商品カタログ | 100ページ分 |
| 過去の提案書 | 20本程度 |
| 就業規則 + 各種規程 | まとめて登録可能 |

「500ページ分」と聞くと、多くの業務で十分な量ではないでしょうか。営業部門なら商品カタログと主要な提案書、法務部門なら契約書テンプレートと社内規程、人事部門なら就業規則と各種マニュアル。1つの業務領域の知識をまるごと登録できる容量です。

:::message
**ファイルの制限**: 1ファイルあたり30MBまで、対応形式はPDF、DOCX、CSV、XLSX、TXT、HTML、JSON、EPUBなど多岐にわたります。画像ファイル（JPEG、PNG、GIF、WebP）もアップロード可能です。ファイル数に上限はありませんが、全ファイルから抽出されたテキストの合計が200Kトークンに収まる必要があります。
:::


## 3.3 作り方ステップバイステップ

それでは、実際にProjectsを作ってみましょう。手順は4つだけです。

### ステップ1: プロジェクトを作成する

claude.aiにログインし、サイドバーの「Projects」をクリックします。「Create Project」ボタンを押すと、新しいプロジェクトの作成画面が開きます。

ここでプロジェクトの名前を設定します。あとで見返したときにすぐわかるよう、**業務内容がわかる名前**をつけましょう。

```
良い例:
  営業提案書アシスタント
  法務契約レビュー
  マーケティング施策立案
  新人研修FAQ

わかりにくい例:
  テスト
  プロジェクト1
  仕事用
```

### ステップ2: ファイルをアップロードする

プロジェクト画面のナレッジセクションに、業務に関連するファイルをドラッグ&ドロップでアップロードします。

アップロードのコツは3つあります。

- **関連性の高い資料を厳選する**: 何でもかんでも入れるより、その業務に直接関係する資料を選ぶほうが、Claudeの回答精度は上がります
- **テキストが読み取れる形式で用意する**: PDFの場合、スキャン画像ではなくテキストが埋め込まれたPDFが理想的です。テキスト抽出が行われるため、画像だけのPDFでは内容を読み取れません
- **最新の情報を優先する**: 古い資料と新しい資料が矛盾する場合、Claudeは判断に迷います。可能であれば最新版をアップロードしましょう

### ステップ3: カスタムインストラクションを設定する

カスタムインストラクションは、そのプロジェクト内でClaudeがどう振る舞うかを指示する設定です。ここに書いた内容は、プロジェクト内のすべての会話に自動的に適用されます。

基本的な構成は、次の3つの要素です。

1. **役割定義**: Claudeにどんな立場で回答してほしいか
2. **出力ルール**: 回答の形式やトーンの指定
3. **注意事項**: やってはいけないことや気をつけてほしいこと

たとえば、営業アシスタントのプロジェクトなら、次のようなカスタムインストラクションが考えられます。

```
あなたは当社（株式会社ABCテクノロジー、ITソリューション企業）の
ベテラン営業担当者です。商品知識に精通し、顧客への提案に長けています。

回答のルール:
- 日本語で、ビジネスに適切なトーンで書いてください
- 結論を先に述べ、その後に根拠を示してください
- 箇条書きを活用してください
- 専門用語を使う場合は、括弧内に簡単な説明を添えてください

注意事項:
- 当社の商品情報はナレッジに登録された資料に基づいてください
- 競合製品を不当に貶める表現は避けてください
- 価格交渉に関わる内容は「営業マネージャーに確認してください」と案内してください
```

:::message
**カスタムインストラクションの書き方**については、第6章で詳しく紹介するプロンプトの原則（役割を与える、具体的に伝える、構造を与える）がそのまま活用できます。この章ではまず「設定できる」ことを知っておいてください。第6章を読んだあとに、より精度の高いカスタムインストラクションに書き直してみるのもおすすめです。
:::

### ステップ4: 会話を開始する

ファイルとカスタムインストラクションの設定が完了したら、プロジェクト内で新しいチャットを開始します。いつものチャット画面と同じように質問するだけで、Claudeはアップロードされた資料とカスタムインストラクションを踏まえて回答してくれます。

試しに、「登録されている資料の概要を教えてください」と聞いてみてください。Claudeがあなたの資料をきちんと認識しているか確認できます。


## 3.4 実践パターン4選 --- あなたの業務に合うのはどれ？

ここからは、Projectsの具体的な活用パターンを4つ紹介します。自分の業務に近いものから試してみてください。

### パターン1: 営業アシスタント

**登録する資料**: 商品カタログ、過去の提案書（成功事例）、価格表、FAQ集

**カスタムインストラクション**:

```
あなたは当社のベテラン法人営業です。
登録されている商品カタログと過去の提案書を踏まえて、
新規顧客向けの提案資料の作成をサポートしてください。
```

**活用シーン**:

```
ユーザー: 製造業の中堅企業（従業員300名）に、
         当社のクラウド勤怠管理システムを提案したいです。
         先方の課題は「紙のタイムカードからの脱却」と
         「残業時間の可視化」です。
         提案書のドラフトを作ってください。
```

Claudeは登録された商品カタログから該当製品の機能・価格を参照し、過去の提案書のトーンやフォーマットに合わせたドラフトを作成してくれます。ゼロから書くのと比べて、初稿の完成速度が格段に上がります。

### パターン2: 法務レビュー

**登録する資料**: 契約書テンプレート、社内規程、過去のレビュー記録

**カスタムインストラクション**:

```
あなたは当社の法務担当者です。
登録されている契約書テンプレートと社内規程に基づいて、
契約書のリスク分析と修正提案を行ってください。
リスクは「高」「中」「低」の3段階で評価してください。
```

**活用シーン**:

```
ユーザー: 取引先から送られてきたNDA（秘密保持契約書）を
         レビューしてください。
         当社のテンプレートと比較して、
         リスクのある条項を指摘してください。

         （NDAのテキストを貼り付け）
```

Claudeは登録されたテンプレートと見比べながら、条項ごとにリスク評価と修正案を提示してくれます。法務部門がない中小企業や、法務の手が回らない場面で特に威力を発揮します。

:::message
**注意**: Claudeの法務レビューはあくまで参考情報です。最終判断は必ず法務の専門家（弁護士・法務担当者）に確認してください。AIは「見落とし防止のセカンドオピニオン」として活用するのが適切です。
:::

### パターン3: マーケティング分析

**登録する資料**: ブランドガイドライン、市場調査データ、過去のキャンペーン実績

**カスタムインストラクション**:

```
あなたは当社のマーケティングストラテジストです。
ブランドガイドラインのトーン&マナーを厳守し、
データに基づいた施策提案を行ってください。
提案には必ず「期待効果」と「KPI」を含めてください。
```

**活用シーン**:

```
ユーザー: 来月のSNSキャンペーンの企画案を3つ出してください。
         ターゲットは20〜30代の女性で、
         予算は50万円以内です。
         過去のキャンペーン実績も踏まえて、
         最も効果が高そうなものを推奨してください。
```

ブランドガイドラインが登録されているので、提案される施策のトーンやビジュアルの方向性が自社のブランドに沿ったものになります。過去の実績データがあれば、「前回のキャンペーンではこの手法が効果的だった」という根拠付きの提案も可能です。

### パターン4: 社内FAQ

**登録する資料**: 就業規則、各種マニュアル、社内制度の説明資料

**カスタムインストラクション**:

```
あなたは当社の総務部の担当者です。
社員からの質問に対して、登録されている就業規則と
各種マニュアルに基づいて回答してください。
回答は簡潔に、該当する規程の条項番号も添えてください。
根拠が見つからない場合は「総務部にお問い合わせください」と案内してください。
```

**活用シーン**:

```
ユーザー: 有給休暇の繰り越しルールを教えてください。
         年度末に残った有給は来年度に持ち越せますか？
```

就業規則が登録されているので、Claudeは該当する条項を参照して正確に回答します。「就業規則第○条に基づき...」と根拠を示してくれるため、回答の信頼性が高まります。

この社内FAQパターンは、総務部門への問い合わせを大幅に減らす効果が期待できます。特に「前に聞いたけど忘れてしまった」「マニュアルのどこに書いてあるかわからない」といった定型的な質問に威力を発揮します。

---

4つのパターンに共通しているのは、**「資料 + 役割 = 専門AI」**というシンプルな構図です。あなたの業務で頻繁に参照する資料があり、繰り返し発生するタスクがあるなら、それはProjectsで効率化できるサインです。


## 3.5 Teamプランでの共有 --- チームのナレッジを共有する

個人で使うだけでもProjectsは強力ですが、**Teamプラン**（Standardシート: 年払い月額$20/ユーザー、月払い$25/ユーザー。最低5名から）を利用すると、プロジェクトをチーム内で共有できます。

たとえば、営業部門で「営業アシスタント」プロジェクトを共有すれば、チーム全員が同じ商品知識とトーンで提案書を作成できます。新人営業が「ベテランのような提案書」を初日から作れるようになるのは、大きなメリットではないでしょうか。

Teamプランでの共有のポイントは以下の通りです。

- **共有プロジェクトの作成**: チーム管理者がプロジェクトを作成し、メンバーに共有できます
- **会話のスナップショット共有**: 有用な会話をチームのアクティビティフィードに共有できます。「こんな質問をしたら、こんな良い回答が返ってきた」という知見をチーム全体に広められます
- **ナレッジの一元管理**: チーム共通の資料を1か所に集約することで、「あの資料どこにある？」という問題を解消できます

:::message
**プライバシーについて**: Team・Enterpriseプランでは、データがClaudeのモデル学習に使用されないことが明確に保証されています。Proプランでも、Settings > Privacy から設定を確認しておくと安心です（設定手順は第2章を参照してください）。社内の機密資料を扱う場合は、Team以上のプランが特におすすめです。
:::


## 3.6 ハンズオン: 自分だけの専門AIを作ってみよう

ここまで読んだら、実際に手を動かしてみましょう。所要時間は10分程度です。

### 準備するもの

- Claudeアカウント（Freeプランでもハンズオンの基本操作は試せます。拡張ナレッジ機能を活用したい場合はPro以上を推奨します）
- 自分の業務に関連する資料1つ（PDF、DOCX、CSVなど何でもOK）

手元に適切な資料がない場合は、自社のWebサイトの会社概要ページをPDFに保存したものでも構いません。

### 手順

**ステップ1**: claude.aiにログインし、サイドバーから「Projects」を開きます。「Create Project」をクリックして、業務がわかる名前をつけてください。（例: 「営業サポート」「社内FAQ」「企画アイデア出し」）

**ステップ2**: 用意した資料をナレッジセクションにアップロードします。

**ステップ3**: カスタムインストラクションに、以下のテンプレートを参考にして設定を書きます。

```
あなたは[あなたの会社名]の[役割]です。
登録されている資料を踏まえて、[業務内容]をサポートしてください。

回答のルール:
- 日本語で簡潔に回答してください
- 結論を先に述べてください
- 根拠がある場合は資料名を示してください
```

**ステップ4**: 新しいチャットを開いて、以下の3つの質問を順番に試してみてください。

```
質問1: 登録されている資料の概要を教えてください。

質問2: [あなたの業務に関する具体的な質問]

質問3: [資料の内容を踏まえた成果物の作成依頼]
```

質問1は「Claudeが資料をちゃんと読めているか」の確認です。質問2で実際の業務に関する質問をして、資料に基づいた回答が返ってくるか試します。質問3では、「提案書のドラフトを書いて」「この内容を要約して」など、具体的な成果物を作ってもらいましょう。

通常のチャットとの違いを実感できるはずです。Claudeが自社の文脈を理解した回答を返してくれることに、きっと驚くのではないでしょうか。


## 3.7 コラム: Projects vs Google NotebookLM

Googleが提供するNotebookLMも、資料をアップロードして対話できるツールとして人気があります。「どちらを使えばいいの？」と迷う方も多いかもしれません。

| 比較項目 | Claude Projects | Google NotebookLM |
|---------|----------------|-------------------|
| **主な用途** | 資料を踏まえた生成・分析・対話 | 資料の理解・要約・Q&A |
| **生成能力** | 提案書、メール、レポートなどを新規生成できる | 資料の要約やQ&Aが中心 |
| **カスタムインストラクション** | 自由に設定可能 | あり（カスタムペルソナ機能） |
| **ファイル容量** | 200Kトークン（英語で約500ページ相当） | 50ソースまで（無料版。有料版は300〜600） |
| **料金** | Pro月額$20から | 無料（有料版あり） |
| **音声機能** | なし | ポッドキャスト風の音声要約を自動生成 |

どちらもカスタムインストラクション（カスタムペルソナ）機能を備えていますが、Projectsの強みは**ナレッジベースとインストラクションが統合されている**点です。資料を登録したうえで「この役割で回答して」と指示を設定することで、知識と役割が一体となった専門AIが構築できます。

一言でまとめると、**NotebookLMは「資料を理解するツール」、Projectsは「資料を踏まえて仕事をするツール」**です。

NotebookLMは、大量の資料の内容を理解したり、質問に答えてもらったりする用途に向いています。一方、Projectsは理解するだけでなく、その知識を使って提案書を書いたり、メールを作成したり、分析レポートを生成したりと、**実際の業務成果物を作り出す**ことができます。

調査・学習フェーズではNotebookLM、実務・生成フェーズではProjects、という使い分けも1つの方法です。


## 3.8 まとめ

この章では、Claudeを「あなたの業務に特化した専門AIアシスタント」に変えるProjects機能を紹介しました。

- **Projectsとは**: 自社資料（ナレッジベース）とカスタムインストラクションを組み合わせて、業務特化のAI環境を構築する機能
- **200Kトークンの容量**: 英語で約500ページ分に相当（日本語はやや少なくなるが業務には十分）。ビジネス書1冊分、契約書テンプレート50種類以上
- **作り方は4ステップ**: プロジェクト作成 → ファイルアップロード → カスタムインストラクション設定 → 会話開始
- **4つの実践パターン**: 営業アシスタント、法務レビュー、マーケティング分析、社内FAQなど、繰り返し発生する業務に特に効果的
- **Teamプランで共有**: チーム全員が同じナレッジにアクセスし、一貫した品質の成果物を生成できる
- **プライバシー**: Team・Enterpriseではモデル学習への不使用が保証。Proもデフォルトで不使用（第2章の設定手順を参照）

Projectsの真価は、使い込むほどに発揮されます。最初はシンプルな資料1つから始めて、徐々に資料を追加し、カスタムインストラクションを磨いていくことで、あなただけの「仕事のパートナー」が育っていきます。

> **次の章では**: もう1つの強力な武器「Artifacts」を紹介します。チャットの中で企画書やフローチャート、Webページといった**完成形の成果物をその場で生成**し、修正を繰り返して仕上げていく---Claudeならではの「共同制作」体験を学びましょう。
