# 第4章: Artifacts --- AIとの共同制作で成果物を直接生成する

あなたはClaudeとチャットしていて、こんな経験をしたことはないでしょうか。「いい感じの回答が返ってきた。でも、これをWordに貼り付けて、フォーマットを整えて、体裁を直して...」。チャットの回答をコピーして別のツールに持っていく作業は、地味に手間がかかります。

もし、チャットの中で**完成形の成果物がそのまま出来上がったら**どうでしょう。企画書のドラフト、業務フローチャート、データのグラフ、さらにはちょっとしたWebツールまで。会話しながら「ここをもう少し詳しく」「色を変えて」と指示するだけで、目の前でどんどん仕上がっていく。

それを実現するのが、**Artifacts**（アーティファクト）です。

前の章では、Projectsを使ってClaudeに「予備知識」を与える方法を学びました。この章では、その知識を活かして**完成形の成果物を直接生成する**方法を学びます。Projectsが「AIの頭を鍛える」機能なら、Artifactsは「AIの手を動かす」機能です。


## 4.1 Artifactsとは --- 「会話しながら完成品を作る共同作業台」

Artifactsを一言で表すなら、**「チャットの隣に現れる共同作業台」**です。

通常のチャットでは、Claudeの回答はすべてテキストとして会話ウィンドウに表示されます。しかしArtifactsを使うと、チャットとは**別の専用ウィンドウ**に成果物が表示されます。画面の右側にプレビューが開き、フォーマットされた文書やフローチャート、Webページなどが、完成形の状態でその場に現れるのです。

```
┌─────────────────────────────────────────────────────────┐
│  Claude チャット画面                                      │
│                                                          │
│  ┌──────────────────┐   ┌─────────────────────────┐     │
│  │  会話ウィンドウ    │   │  Artifact ウィンドウ     │     │
│  │                   │   │                          │     │
│  │ あなた:           │   │  ┌────────────────────┐ │     │
│  │ 「業務フローを     │   │  │ 受注プロセス       │ │     │
│  │  図にして」        │   │  │                    │ │     │
│  │                   │   │  │  受注 → 在庫確認   │ │     │
│  │ Claude:           │   │  │   → 出荷 → 請求   │ │     │
│  │ 「業務フローを     │   │  │                    │ │     │
│  │  作成しました」    │   │  └────────────────────┘ │     │
│  │                   │   │                          │     │
│  │ あなた:           │   │  [コピー] [ダウンロード] │     │
│  │ 「承認ステップを   │   │  [共有]                  │     │
│  │  追加して」        │   │                          │     │
│  └──────────────────┘   └─────────────────────────┘     │
└─────────────────────────────────────────────────────────┘
```

ポイントは、この作業台が**対話的**であることです。最初の成果物を見て「ここを直して」と言えば、Claudeはその場で修正してくれます。「色を変えて」「項目を追加して」「もっとシンプルに」。こうした修正指示を繰り返すことで、成果物がどんどん磨かれていきます。

たとえるなら、ホワイトボードの前で同僚と一緒にアイデアを練り上げるような感覚です。あなたが方向性を示し、Claudeが形にする。気に入らなければやり直す。この繰り返しで、1人では時間がかかる成果物が短時間で完成します。

:::message
**利用プラン**: ArtifactsはFree、Pro、Max、Team、Enterpriseの全プランで利用できます。追加の設定も不要で、Claudeに「フローチャートを作って」「HTMLページを作って」と頼むだけで自動的にArtifactウィンドウが開きます。
:::


## 4.2 何が作れるのか --- 生成できる成果物一覧

Artifactsで生成できる成果物は、想像以上に多彩です。ビジネスパーソンにとって特に役立つものを中心に紹介します。

### フォーマット済みドキュメント

最も基本的な使い方です。企画書、報告書、マニュアルなどを、見出し・箇条書き・表を含んだ**きれいに整形された文書**として生成できます。通常のチャット回答をコピペするのとは違い、そのまま資料として使えるレベルのフォーマットで仕上がります。

```
プロンプト例:
「新入社員向けの出張精算マニュアルを作成してください。
 手順を番号付きで、注意事項は目立つように記載してください」
```

### Mermaidダイアグラム（フローチャート・組織図・プロセス図）

ビジネスパーソンにとって、Artifactsの最も実用的な機能の1つがこれです。**業務フロー、承認プロセス、組織図、プロジェクトの進行図**などを、会話するだけで自動生成してくれます。

従来、フローチャートを作るにはPowerPointやVisio、あるいはDraw.ioなどの専用ツールを使い、ボックスを配置して矢印を引いて...と手間がかかりました。Artifactsなら、「経費精算の承認フローを図にして」と頼むだけで、数秒でフローチャートが完成します。

```
プロンプト例:
「当社の経費精算プロセスを図にしてください。
 申請者 → 上長承認 → 経理確認 → 振込 の流れで、
 差し戻しのパターンも含めてください」
```

Claudeは「Mermaid」という図表記述言語を使って図を生成しますが、あなたがMermaidの書き方を覚える必要はまったくありません。日本語で「こういう図を作って」と伝えるだけで、Claudeが適切な形式で描いてくれます。

### HTMLページ（Webツール・ランディングページ）

これがArtifactsの真骨頂とも言える機能です。**プログラミングの知識がなくても、動くWebページやちょっとした業務ツールを作れます。**

たとえば、こんなものが「会話するだけ」で作れます。

- **計算ツール**: 見積もり金額の自動計算、ROI算出ツール
- **チェックリスト**: プロジェクトの進捗管理、タスク一覧
- **ランディングページ**: イベント案内ページ、社内お知らせページ
- **データ入力フォーム**: 簡易的なアンケートフォーム、日報入力画面

```
プロンプト例:
「見積書の金額を自動計算するWebツールを作ってください。
 品名、単価、数量を入力すると合計金額が表示されるようにしてください。
 消費税（10%）も自動計算してください」
```

このプロンプトを送ると、Claudeは入力フォームと計算ロジックを含んだHTMLページをArtifactウィンドウに生成します。その場でフォームに数値を入力して動作を確認でき、問題があればすぐに修正を依頼できます。

:::message
**プログラミング不要**: Artifactsの最大の魅力は、HTML、CSS、JavaScriptといったプログラミングの知識がなくても業務ツールを作れることです。必要なのは「こういうツールが欲しい」という日本語の説明だけ。裏側のコードはClaudeが全部書いてくれます。
:::

### SVG画像（アイコン・図解・概念図）

プレゼン資料に使えるシンプルなアイコンや概念図も生成できます。写真のようなリアルな画像は作れませんが、ビジネス向けの図解やダイアグラムには十分です。

```
プロンプト例:
「PDCAサイクルの概念図をSVGで作成してください。
 Plan、Do、Check、Actの4つが円を描くように配置してください」
```

### データ可視化（グラフ・チャート）

売上データや調査結果をインタラクティブなグラフとして可視化できます。棒グラフ、折れ線グラフ、円グラフなど、データの種類に応じた表現が可能です。マウスを重ねると数値が表示される、といったインタラクティブな操作もできます。

```
プロンプト例:
「以下の売上データを棒グラフで可視化してください。
 1月: 320万円、2月: 280万円、3月: 410万円、
 4月: 390万円、5月: 450万円、6月: 520万円
 月ごとの推移がわかりやすいようにしてください」
```

---

これらの成果物をまとめると、次のようになります。

| 成果物の種類 | ビジネスでの用途 | プログラミング知識 |
|-------------|-----------------|-------------------|
| ドキュメント | 企画書、マニュアル、報告書 | 不要 |
| Mermaidダイアグラム | 業務フロー、組織図、プロセス図 | 不要 |
| HTMLページ | 計算ツール、チェックリスト、LP | 不要 |
| SVG画像 | 概念図、アイコン、図解 | 不要 |
| データ可視化 | グラフ、チャート、ダッシュボード | 不要 |

右端の列に注目してください。すべて「不要」です。**必要なのは日本語で「こういうものを作ってほしい」と伝えることだけ**。これがArtifactsの最大の価値です。


## 4.3 ビジネスでの活用パターン4選

Artifactsの機能がわかったところで、実際のビジネスシーンでどう活かすのかを見ていきましょう。

### パターン1: 企画書のドラフト → 修正 → 完成

最もシンプルな活用法です。企画書や報告書のドラフトをArtifactとして生成し、「ここを修正して」と対話しながら完成させます。

```
ステップ1（初稿を依頼）:
「社内DX推進の企画書を作成してください。
 対象は経営会議向け、A4で3ページ相当の分量でお願いします」

ステップ2（修正を指示）:
「導入効果のセクションに、具体的な数値目標を追加してください。
 例えば『月間の事務作業時間を30%削減』のような形で」

ステップ3（仕上げ）:
「全体を読み返して、経営層に刺さる表現に修正してください。
 特に冒頭のサマリーを力強くしてください」
```

通常のチャットでも同じことはできますが、Artifactsの場合は**右側のウィンドウで成果物の全体像を見ながら修正指示が出せる**のが大きな違いです。長い文書の場合、チャットの会話が流れてしまって全体を把握しにくくなりますが、Artifactは常に最新版が表示されています。

### パターン2: 業務フローの可視化

「うちの業務フローを図にしたい」。マニュアル作成や業務改善のとき、誰もが一度は思うことではないでしょうか。しかし、PowerPointで四角形と矢印を並べるのは意外に手間がかかります。

Artifactsなら、文章で業務の流れを伝えるだけでフローチャートが完成します。

```
プロンプト例:
「以下の受注処理フローをMermaid図にしてください。

1. 顧客から注文を受ける
2. 在庫を確認する
3. 在庫があれば出荷手配、なければ顧客に納期を連絡
4. 出荷後、請求書を発行する
5. 入金を確認する
6. 入金確認後、案件をクローズする」
```

生成された図を見て「承認ステップが抜けているから追加して」「例外パターンも入れて」と修正を重ねれば、数分で実用的な業務フロー図が完成します。これをマニュアルに貼り付けたり、チームに共有したりすれば、業務の可視化がぐっと進みます。

### パターン3: データの可視化 → プレゼン活用

売上データや調査結果をグラフにして、プレゼン資料に使いたい。そんなとき、Excelでグラフを作るのも1つの方法ですが、Artifactsならインタラクティブで見栄えの良いグラフが会話だけで作れます。

```
プロンプト例:
「以下のデータを、月次推移がわかる折れ線グラフにしてください。
 前年比の数字も併記してください。

 2025年: 1月320万、2月280万、3月410万...
 2026年: 1月380万、2月350万、3月490万...」
```

生成されたグラフを見て、「色をもっとビジネスっぽく」「凡例を上に移動して」「グラフタイトルを大きくして」といった修正も自在です。気に入ったグラフは画像としてダウンロードし、PowerPointに貼り付けて使えます。

### パターン4: 簡易Webツール → リンクで社内共有

最も可能性を感じるのがこのパターンです。ちょっとした計算ツールやチェックリストを作り、**リンク1つでチームに共有**できます。

たとえば、営業チームで見積もり金額の計算にいつもExcelのテンプレートを使っているとしましょう。Artifactsで「見積もり計算ツール」を作れば、ブラウザだけで使えるツールが完成します。

```
プロンプト例:
「営業チーム用の見積もり計算ツールを作ってください。

 機能:
 - 品名、単価、数量を複数行入力できる
 - 小計と合計を自動計算
 - 消費税（10%）を自動計算
 - 値引き率を入力すると割引後の金額を表示
 - 印刷しやすいレイアウト」
```

完成したツールはリンクを生成して共有できるので、チームメンバーはそのリンクを開くだけで使えます。IT部門に開発を依頼する必要も、外部サービスを契約する必要もありません。

:::message
**Projectsとの組み合わせ**: 第3章で学んだProjectsにあらかじめ自社の情報を登録しておけば、Artifactsでの成果物生成がさらに的確になります。たとえば「営業アシスタント」Projectに商品カタログを登録したうえで「商品Aの見積もり計算ツールを作って」と頼めば、実際の価格体系に基づいたツールが生成されます。機能を組み合わせることで、実用性が大きく向上します。
:::


## 4.4 「もっと良くして」の繰り返しで品質を上げるコツ

Artifactsの真価は、最初の出力ではなく**修正の繰り返し**にあります。1回目の生成で完璧なものが出てくることは稀です。しかし、2回、3回と修正を重ねるたびに、あなたの意図に近づいていきます。

効果的な修正指示のコツを3つ紹介します。

### コツ1: 具体的に指摘する

「もっと良くして」「いい感じにして」といった曖昧な指示では、Claudeはどこをどう変えればよいか判断できません。

```
曖昧な指示:
「もっと見やすくして」

具体的な指示:
「表の列幅を均等にして、ヘッダー行の背景色を青にしてください。
 金額の列は右揃えにしてください」
```

### コツ2: 1回の修正で1つの変更

複数の修正を一度に依頼すると、意図通りに反映されないことがあります。大きな変更は1つずつ依頼するのがおすすめです。

```
避けたい指示:
「色を変えて、項目を追加して、レイアウトも変えて、
 フォントも変えてください」

おすすめの進め方:
1回目:「ヘッダーの色を紺色に変えてください」
2回目:「承認ステップの項目を追加してください」
3回目:「全体のレイアウトを横並びに変更してください」
```

### コツ3: 良い部分を伝えてから修正点を指摘する

Claudeは「どこが良かったか」のフィードバックも参考にします。良い部分を維持しつつ改善してもらうために、「ここは良いので残して、ここだけ変えて」と伝えましょう。

```
「全体の構成はとてもいいです。
 ただ、第2セクションの説明が少し抽象的なので、
 具体的な数値を入れて説得力を高めてください。
 それ以外のセクションはそのままでお願いします」
```

この「段階的に磨き上げる」というアプローチは、第6章で紹介するプロンプトの原則5「段階的に進める」と同じ考え方です。一発で完璧を目指すのではなく、対話を重ねて完成度を上げていく。これがArtifactsを最大限に活用するコツです。


## 4.5 共有機能 --- リンク1つでチームに配布

Artifactsで作った成果物は、**リンクを生成するだけでチームメンバーに共有**できます。Free、Pro、Maxプランのユーザーが利用可能です。

共有の手順はシンプルです。Artifactウィンドウの共有ボタンをクリックするだけで、共有用のリンクが生成されます。このリンクを受け取った人は、Claudeのアカウントがなくてもブラウザで成果物を閲覧・操作できます。

これが特に威力を発揮するのは、HTMLで作成した業務ツールの共有です。たとえば、先ほど紹介した見積もり計算ツールをリンクで営業チームに配布すれば、全員がブラウザ上でツールを使えます。サーバーの設定やアプリのインストールは一切不要です。

```
活用の流れ:
1. Claudeに業務ツールを作ってもらう
2. 動作を確認して、修正を重ねる
3. 完成したら共有リンクを生成
4. SlackやメールでチームにURLを送る
5. メンバーはリンクを開くだけで利用開始
```

これまで「こういうツールがあったら便利なのに」と思いながら、IT部門への依頼が面倒で諦めていた小さな業務改善が、Artifactsの共有機能で実現できるようになります。


## 4.6 ファイル作成機能 --- Excel・PowerPoint・PDFを直接生成

Artifactsの応用機能として、**Excelスプレッドシート（.xlsx）、PowerPointプレゼンテーション、PDF**を直接生成するファイル作成機能があります。

```
プロンプト例:
「以下のデータをExcelファイルにまとめてください。
 シート1: 月別売上一覧（1月〜6月）
 シート2: 商品カテゴリ別の集計
 合計行とグラフも含めてください」
```

このように依頼すると、Claudeがファイルを生成し、ダウンロードできる状態で表示されます。ダウンロードしたファイルは、そのままExcelやPowerPointで開いて編集できます。

:::message
**対応プラン**: ファイル作成機能は現在、Max、Team、Enterpriseプランで利用可能です。Proプランへも順次開放が予定されています。この機能がなくても、ArtifactsでHTMLの表やグラフを作成し、手動でExcelに転記するという方法で代替できます。
:::


## 4.7 ハンズオン: 自分の業務フローをMermaid図にしてみよう

ここまで読んだら、実際にArtifactsを体験してみましょう。お題は「自分の業務フローの可視化」です。所要時間は10分程度です。

### 準備するもの

- Claudeアカウント（無料プランでOK）
- 自分が日常的に行っている業務の流れを思い浮かべておく

マニュアル化されていなくても構いません。頭の中にある「いつもやっている手順」で十分です。

### 手順

**ステップ1: 業務の流れを伝える**

claude.aiで新しいチャットを開き、以下のように入力してください。`[あなたの業務]` の部分は、自分の実際の業務に置き換えます。

```
私の[あなたの業務]の流れをMermaid図（フローチャート）にしてください。

手順:
1. [最初のステップ]
2. [次のステップ]
3. [その次のステップ]
...

条件分岐がある場合:
- [条件]の場合は[Aの手順]
- [条件]でない場合は[Bの手順]
```

具体的な例を1つ挙げます。

```
私の「顧客からの問い合わせ対応」の流れをMermaid図にしてください。

手順:
1. メールまたは電話で問い合わせを受ける
2. 内容を確認し、カテゴリを判別する（技術的/営業的/その他）
3. 技術的な場合は技術チームにエスカレーション
4. 営業的な場合は自分で回答を作成
5. その他の場合は総務に転送
6. 回答をお客様に送付
7. 対応履歴をCRMに記録
```

Claudeがフローチャートを生成し、Artifactウィンドウに表示されます。

**ステップ2: 修正を依頼する**

生成された図を見て、「ここが違うな」「この手順が抜けている」と感じた部分を修正してもらいましょう。

```
修正例:
「ステップ4で回答を作成した後、上長の承認を得るステップを追加してください」

「技術チームにエスカレーションした後、回答が返ってきたらお客様に転送する
 フローも追加してください」

「対応完了後にお客様満足度アンケートを送るステップも入れてください」
```

**ステップ3: 仕上げ**

基本的な流れが完成したら、見た目を整えましょう。

```
「図のタイトルを『顧客問い合わせ対応フロー（2026年2月版）』にしてください」

「条件分岐の部分を色分けしてください。
 技術的=青、営業的=緑、その他=グレー」
```

完成した図は、コピーボタンでMermaidコードを取得できます。このコードは、社内のドキュメント管理ツールやマニュアルにそのまま貼り付けて使えます。また、画像としてダウンロードすれば、PowerPointやWordにも貼り付けられます。

たった10分で、頭の中にしかなかった業務フローが目に見える図になりました。これをチームに共有すれば、業務の引き継ぎや改善の議論がずっとスムーズになるはずです。


## 4.8 コラム: ChatGPT Canvas vs Claude Artifacts

ChatGPTにも「Canvas」という似た機能があります。どちらも「チャットの隣で成果物を作る」点は同じですが、得意分野が異なります。

| 比較項目 | Claude Artifacts | ChatGPT Canvas |
|---------|-----------------|----------------|
| **対応形式** | HTML、Mermaid、SVG、React等、多様な形式 | テキスト・コードの編集が中心 |
| **Webアプリ生成** | インタラクティブなWebツールを生成可能 | 限定的 |
| **直接編集** | インライン編集が導入済み。チャット指示 + 差分更新の併用 | 成果物を直接クリックして編集できるUIが充実 |
| **共有機能** | リンク生成で誰にでも配布可能 | 共有機能あり |
| **得意な用途** | 業務ツール作成、図解、データ可視化 | 文章の推敲、コードの編集 |

一言でまとめると、**Canvasは「文章やコードをその場で直す」ことに特化**しており、**Artifactsは「多様な形式の成果物を生成・共有する」ことに強い**と言えます。

ビジネスパーソンにとっては、業務フローの可視化、計算ツールの作成、データのグラフ化など、Artifactsの「多様な形式への対応力」が実務で大きな武器になります。一方、長い文章を書いている途中で特定の段落だけ手直ししたい場合は、Canvasの直接編集UIが便利です。

どちらか一方が優れているというよりも、用途に応じて使い分けるのが賢い選択です。


## 4.9 まとめ

この章では、Claudeとの「共同制作」を可能にするArtifacts機能を紹介しました。

- **Artifactsとは**: チャットの隣に開く共同作業台。完成形の成果物をその場で生成・プレビュー・修正できる
- **生成できるもの**: ドキュメント、Mermaidダイアグラム（フローチャート・組織図）、HTMLページ（業務ツール）、SVG画像、データ可視化。すべてプログラミング知識不要
- **ビジネス活用**: 企画書の対話的ブラッシュアップ、業務フローの可視化、インタラクティブなグラフ、簡易Webツールの作成と共有
- **品質を上げるコツ**: 具体的に修正点を伝える、1回1変更、良い部分を残す指示を出す。対話を重ねて完成度を上げていく
- **共有機能**: リンク1つでチームに配布可能。HTMLツールはブラウザだけで使える
- **ファイル作成**: Max/Team/Enterpriseプランでは、Excel・PowerPoint・PDFの直接生成にも対応（Proへの順次開放を予定）
- **Projectsとの併用**: 自社資料をProjectsに登録した状態でArtifactsを使えば、文脈に合った成果物が生成できる

Artifactsは「AIに聞く」から「AIと作る」への転換点です。チャットで情報を得るだけでなく、成果物を一緒に作り上げていく。この体験は、日々の業務の進め方を大きく変えてくれるはずです。
