# 第5章: ファイル連携 & Claude in Excel --- データをAIで即分析

あなたのパソコンには、読まなければいけないPDFレポート、整理したいExcelデータ、テキスト化したい名刺の写真が溜まっていないでしょうか。これまでの章では、チャットでテキストを入力し、Claudeに回答やArtifactsを生成してもらう使い方を学びました。しかし、実際のビジネスでは「すでに手元にあるデータ」をどう活かすかが勝負です。

この章では、Claudeの**ファイル連携機能**を使って、PDFやExcel、CSV、画像といった手元のファイルをAIに読み込ませ、分析・要約・可視化する方法を学びます。さらに、Excel上で直接AIに分析を依頼できる**Claude in Excel**アドインも紹介します。

前章のArtifactsが「AIと一緒に新しい成果物を作る」機能だったのに対し、この章のファイル連携は「すでにあるデータをAIの力で読み解く」機能です。入力と出力、両方向からClaudeを使いこなせるようになれば、あなたのデータ活用力は飛躍的に高まります。


## 5.1 ファイルアップロードの基本

### 対応形式と制限

Claudeは、ビジネスで日常的に使われるほとんどのファイル形式に対応しています。

| カテゴリ | 対応形式 |
|---------|---------|
| ドキュメント | PDF, DOCX, XLSX, CSV, TXT, HTML, ODT, RTF, EPUB, JSON |
| 画像 | JPEG, PNG, GIF, WebP |

制限事項も押さえておきましょう。

| 項目 | 制限値 |
|------|--------|
| 1ファイルあたりの上限 | 30MB |
| 1チャットあたりのファイル数 | 最大20ファイル |
| 画像の解像度上限 | 8,000 x 8,000ピクセル |

### アップロードの手順

操作はとてもシンプルです。claude.aiのチャット画面で、入力欄の左にあるクリップアイコンをクリックし、ファイルを選択するだけです。ドラッグ&ドロップでも構いません。ファイルが読み込まれると、入力欄の上にファイル名が表示されます。

```
アップロードの流れ:

1. claude.ai でチャットを開く
2. 入力欄の左のクリップアイコンをクリック
   （またはファイルをドラッグ&ドロップ）
3. ファイルが読み込まれたことを確認
4. 「このファイルを要約してください」等の指示を入力
5. 送信
```

複数ファイルを同時にアップロードすることもできます。たとえば、3つのPDFレポートを一度にアップロードして「3つの報告書の共通点と相違点をまとめてください」と依頼する、といった使い方が可能です。

:::message
**Projectsのファイルとの違い**: 第3章で紹介したProjectsにもファイルをアップロードする機能がありました。Projectsのファイルは「そのProject内のすべてのチャットで参照される永続的な知識」になります。一方、この章で紹介するチャットへの直接アップロードは「そのチャット内でだけ参照される一時的なファイル」です。常に参照したいマニュアルや規定はProjectsに、その場で分析したいデータはチャットに直接アップロードする、と使い分けましょう。
:::


## 5.2 PDF分析の実践

ビジネスパーソンが最も頻繁にアップロードするのはPDFでしょう。社内レポート、業界調査、契約書、マニュアル。PDFは大量にあるのに、読む時間は限られている。Claudeにその負担を肩代わりしてもらいましょう。

### PDFの処理方法

Claudeは、PDFを次のように処理します。

| ページ数 | 処理方法 |
|---------|---------|
| 100ページ以下 | テキスト + ビジュアル要素（画像、チャート、グラフ）の両方を分析 |
| 100ページ超 | テキストのみの処理（画像やグラフは読めない） |

100ページ以下のPDFであれば、文中のグラフや図表の内容まで読み取ってくれるのが大きなポイントです。たとえば、レポートに含まれる棒グラフを見て「売上は4月にピークを迎えています」といった分析ができます。

### パターン1: 長文レポートの要約

50ページの業界調査レポートを読む時間がない。そんなときの定番パターンです。

```
プロンプト例:
「このPDFレポートを以下の形式で要約してください。

1. 3行サマリー（忙しい上司に30秒で伝える用）
2. 重要なポイント5つ（箇条書き）
3. 数値データのハイライト（特に注目すべき統計）
4. 自社ビジネスへの示唆（当社はSaaS企業です）」
```

ポイントは「どんな形式で要約してほしいか」を具体的に伝えることです。単に「要約して」だけでは、あなたが求めている粒度の要約が返ってくるとは限りません。用途（誰に見せるか、何の判断に使うか）を添えると、さらに的確な要約になります。

### パターン2: 複数PDFの比較分析

2つ以上のPDFをアップロードして比較する使い方も強力です。

```
プロンプト例:
「アップロードした2つのPDFは、2024年版と2025年版の市場調査レポートです。
以下の観点で比較分析してください。

- 市場規模の変化
- 主要プレイヤーの順位変動
- 新たに登場したトレンド
- 数値データの前年比較（表形式で）」
```

人間が2つの長文レポートを突き合わせて比較するのは、集中力と時間を要する作業です。Claudeにまず大枠の比較をしてもらい、気になるポイントを深掘りしていくアプローチが効率的です。

### パターン3: 特定データの抽出

PDFの中から特定の情報だけを抜き出す作業も、Claudeの得意分野です。

```
プロンプト例:
「この契約書PDFから、以下の情報を抽出してください。

- 契約期間（開始日・終了日）
- 契約金額
- 支払い条件
- 解約条件
- 特記事項・注意すべき条項

表形式でまとめてください」
```

契約書のレビューや、アンケートの自由記述欄の分類など、「大量のテキストから特定のパターンを見つけ出す」タスクはClaudeが特に力を発揮する場面です。


## 5.3 CSV/Excelデータの分析

売上データ、顧客リスト、アンケート結果。ビジネスで扱うデータの多くはCSVやExcel形式で存在しています。これらをClaudeにアップロードすると、自然言語で「質問」するだけで分析結果が返ってきます。

### 基本的な分析フロー

```
CSV/Excelデータ分析の3ステップ:

1. データをアップロード
2. 日本語で質問する
3. 分析結果・グラフが返ってくる
```

たとえば、月別の売上データが入ったCSVファイルをアップロードして、次のように聞くだけです。

```
プロンプト例（売上データを添付した状態で）:
「このデータについて教えてください。
- 前年比で最も伸びている商品カテゴリは？
- 売上が落ちている月とその原因の仮説は？
- 上位5商品の売上推移を折れ線グラフで可視化してください」
```

Claudeはデータの構造を自動的に把握し、列名や数値の意味を理解した上で回答してくれます。SQLやPythonの知識は一切不要です。

### 効果的な質問のコツ

データ分析を依頼するときは、以下の点を意識すると的確な結果が返ってきます。

```
曖昧な質問:
「このデータを分析して」

具体的な質問:
「このデータについて以下の分析をお願いします。
1. 売上の月別推移を棒グラフで表示
2. 前年同月比の増減率を計算
3. 売上上位10商品のランキング表
4. 季節性のパターンがあれば指摘してください」
```

「分析して」だけでは、Claudeはどこに注目すべきか判断に迷います。「何を」「どういう形式で」知りたいのかを伝えることで、分析の精度が大きく変わります。これは次の第6章で詳しく紹介するプロンプトの原則にも通じる考え方です。

### グラフ生成

CSVやExcelデータをアップロードすると、Claudeはデータをもとにグラフを生成できます。棒グラフ、折れ線グラフ、円グラフ、散布図など、データの性質に応じた可視化が可能です。前章で紹介したArtifactsのグラフ生成と似ていますが、違いは**実際のデータファイルに基づいている**点です。チャット内に数値を手入力する必要がなく、数千行のデータでも対応できます。

```
プロンプト例:
「アップロードした売上データを使って、以下のグラフを作ってください。
- 横軸: 月（1月〜12月）
- 縦軸: 売上金額（万円）
- 2024年と2025年の折れ線を重ねて比較
- 色は2024年をグレー、2025年を青にしてください」
```


## 5.4 画像の読み取りと分析

Claudeはテキストファイルだけでなく、画像も読み取れます。ビジネスシーンで特に役立つパターンを3つ紹介します。

### 名刺の読み取り

展示会やセミナーで大量にもらった名刺。1枚ずつ手入力するのは大変な作業です。名刺の写真をまとめてアップロードすれば、Claudeがテキストデータに変換してくれます。

```
プロンプト例（名刺の写真を添付）:
「この名刺の写真からテキスト情報を抽出してください。
以下の形式でお願いします。

会社名:
部署:
役職:
氏名:
電話番号:
メールアドレス:
住所:」
```

複数枚の名刺を一度にアップロードすれば、表形式でまとめてもらうこともできます。そのままCSVに変換してもらえば、顧客管理ツールへのインポートも簡単です。

### グラフ画像からの数値読み取り

紙の報告書やスクリーンショットに含まれるグラフから、数値を読み取ることもできます。

```
プロンプト例（グラフ画像を添付）:
「このグラフ画像から読み取れる数値をすべて表にまとめてください。
その上で、目立つ傾向やポイントを3つ挙げてください」
```

過去の紙資料をデジタルデータとして活用したい場面で特に便利です。

### ホワイトボードのメモ化

会議でホワイトボードに書いた内容を写真に撮って、Claudeに構造化してもらうパターンも実用的です。

```
プロンプト例（ホワイトボード写真を添付）:
「この会議のホワイトボード写真を、以下の形式で議事メモに
まとめてください。

- 議題
- 決定事項
- アクションアイテム（担当者・期限つき）
- 次回までの宿題」
```

走り書きでも、Claudeは文脈を読み取って構造化した文書に変換してくれます。会議後すぐに議事録を共有できるようになります。


## 5.5 Claude in Excel --- スプレッドシート上でAIを使う

ここまでは「Claudeのチャット画面にファイルをアップロードする」方法を紹介してきました。ここからは、逆のアプローチを見てみましょう。**Excel上にClaudeを呼び込む**方法です。

### Claude in Excelとは

Claude in Excelは、Microsoft Excelのアドインとして動作する機能です。Excelを開いた状態で、サイドパネルにClaudeが常駐し、自然言語でスプレッドシートの分析・編集・作成を依頼できます。

```
┌─────────────────────────────────────────────────────┐
│  Excel ウィンドウ                                     │
│                                                      │
│  ┌──────────────────────┐  ┌─────────────────────┐  │
│  │  スプレッドシート      │  │  Claude パネル      │  │
│  │                       │  │                      │  │
│  │  A    B      C        │  │ あなた:              │  │
│  │  商品  売上   前年比   │  │ 「前年比がマイナス   │  │
│  │  A    520万  +12%     │  │  の商品に赤色の      │  │
│  │  B    180万  -8%      │  │  条件付き書式を      │  │
│  │  C    340万  +25%     │  │  設定して」          │  │
│  │  D    90万   -15%     │  │                      │  │
│  │  ...                  │  │ Claude:              │  │
│  │                       │  │ 「C列にマイナスの    │  │
│  │                       │  │  条件付き書式を      │  │
│  │                       │  │  適用しました」      │  │
│  └──────────────────────┘  └─────────────────────┘  │
└─────────────────────────────────────────────────────┘
```

つまり、Excelでデータを見ながら「ここをこう分析して」「この形式に整えて」とAIに直接話しかけられるのです。ブラウザとExcelを行き来する必要がありません。

:::message
**利用プラン**: Claude in Excelは、Pro、Max、Team、Enterpriseプランで利用できます（ベータ版）。対応ファイル形式は .xlsx および .xlsm です。2025年10月にリサーチプレビューとしてスタートし、2026年1月にProプラン全ユーザーに展開されました。
:::

### インストール方法

Claude in Excelのインストールは、通常のExcelアドインの追加手順と同じです。

```
インストール手順:
1. Excelを開く
2. 「挿入」タブ → 「アドインを取得」をクリック
3. 検索ボックスに「Claude」と入力
4. 「Claude for Excel」を選択して「追加」
5. Claudeアカウントでサインイン
6. サイドパネルにClaudeが表示されれば完了
```

### できること

Claude in Excelでは、以下のことが自然言語で実行できます。

**データの質問・分析**

スプレッドシートの内容について、日本語で質問できます。Claudeはセル番号を引用しながら回答してくれるので、「どのデータを見て答えたのか」が明確です。

```
質問の例:
「売上が最も高い月はどこですか？」
「A列の商品名ごとに、B列の売上を合計するとどうなりますか？」
「このデータに異常値はありますか？」
```

**数式の作成**

関数の書き方がわからなくても、やりたいことを日本語で伝えれば、Claudeが適切な数式を入力してくれます。

```
依頼の例:
「D列に、B列の売上とC列の原価から粗利率を計算する数式を入れてください」
「E列に、A列の商品名をもとにシート2から単価を検索する数式を入れてください」
```

VLOOKUPやXLOOKUP、INDEX-MATCHといった複雑な関数も、Claudeが適切に選んで入力してくれます。

**グラフ作成・編集**

```
依頼の例:
「A列とB列のデータから、月別売上の棒グラフを作成してください」
「このグラフの凡例を上部に移動して、色を青と緑にしてください」
```

**ピボットテーブル・条件付き書式**

```
依頼の例:
「商品カテゴリ別の売上集計ピボットテーブルを作ってください」
「売上が100万円以下のセルを赤色にハイライトしてください」
```

**エラーの修正**

Excel作業で地味にストレスなのが、#REF! や #VALUE! などのエラーです。Claude in Excelはエラーの原因を特定し、修正方法を提案してくれます。

```
依頼の例:
「F3セルに #REF! エラーが出ています。原因を教えてください」
「循環参照の警告が出ているのですが、どのセルが原因ですか？」
```

### できないこと

Claude in Excelにも制約があります。以下は現時点で対応していない操作です。

| 操作 | 状況 |
|------|------|
| マクロの作成・実行 | 非対応 |
| VBAコードの記述 | 非対応 |
| データテーブル機能 | 非対応 |

マクロやVBAが必要な場面では、Claudeのチャット画面でVBAコードを生成してもらい、それをExcelのVBAエディタに貼り付ける、という方法で対応できます。直接実行はできませんが、コード作成の手間は大幅に減ります。

### 安全性への配慮

Claude in Excelが行った変更は、すべて追跡・強調表示されます。Claudeが勝手にデータを書き換えてしまう心配はありません。変更箇所がハイライトされるので、内容を確認してから承認する形で運用できます。また、既存の数式の依存関係を保持したまま編集が行われるため、他のセルへの影響も最小限に抑えられます。


## 5.6 実践: PDF → Excel → PowerPoint の変換フロー

ここまで学んだ機能を組み合わせると、ビジネスパーソンの定番作業「会議資料の準備」が劇的に変わります。PDF形式の報告書を受け取り、データをExcelで整理し、最終的にPowerPointのスライドに仕上げる、あの一連のフローです。

### 従来のフローとClaudeを活用したフロー

```
【従来のフロー】
PDFレポートを受け取る
  → 目を通して要点をメモ（30分）
  → Excelにデータを手入力（20分）
  → グラフを作成（15分）
  → PowerPointにまとめる（30分）
  合計: 約1.5〜2時間

【Claudeを活用したフロー】
PDFレポートをClaudeにアップロード
  → 「要点を抽出してExcel形式の表にして」（2分）
  → 「このデータを棒グラフで可視化して」（1分）
  → 「この内容を5枚のスライド構成にまとめて」（3分）
  → 内容を確認・修正（10分）
  合計: 約15〜20分
```

### 具体的な手順

**ステップ1: PDFの要点を抽出**

```
プロンプト例（PDFを添付して）:
「この月次報告書から、以下のデータを表形式で抽出してください。
- 部門別の売上実績
- 前月比と前年同月比
- 達成率
- 特記事項」
```

**ステップ2: データの整理と可視化**

抽出されたデータをもとに、グラフの作成を依頼します。

```
プロンプト例:
「抽出してもらったデータから、以下のグラフを作ってください。
1. 部門別売上の棒グラフ（前年比較つき）
2. 達成率の一覧表（未達の部門を赤字で表示）」
```

**ステップ3: スライド構成の作成**

```
プロンプト例:
「ここまでの分析内容を、経営会議向けの5枚スライド構成に
まとめてください。

スライド1: サマリー（全社売上・前年比・一言コメント）
スライド2: 部門別実績（グラフ + 数値表）
スライド3: 注目トピック（特に伸びた/落ちた部門）
スライド4: 課題と対策案
スライド5: 次月の見通し」
```

:::message
**ファイル生成について**: Max、Team、Enterpriseプランでは、ArtifactsのファイルCreate機能を使ってExcelファイルやPowerPointファイルを直接生成・ダウンロードできます。Proプランでも順次開放が予定されています。この機能がまだ使えない場合は、Claudeが生成した表やテキストを手動でExcel/PowerPointに貼り付けて仕上げましょう。
:::

このフローの本質は、「人間がやるべきでない作業」をClaudeに任せ、「人間がやるべき作業」に集中することです。データの転記や整形はClaudeに任せ、あなたは内容の確認と意思決定に集中する。これが、AIを活用したデータワークの理想形です。


## 5.7 ハンズオン: 手持ちのCSV/Excelファイルを分析してみよう

では、実際にファイル連携を体験してみましょう。手元にCSVやExcelファイルがあればそれを使いますが、なければ以下の手順でサンプルデータをClaudeに作ってもらうところから始められます。

### 準備

**手元にデータがある場合**: そのまま次のステップへ進みましょう。

**手元にデータがない場合**: まず、Claudeにサンプルデータを生成してもらいます。

```
プロンプト例:
「架空の飲食チェーン（5店舗）の月別売上データ（2025年1月〜12月）
のサンプルCSVを作成してください。
各店舗の売上には季節変動を含めてください」
```

生成されたCSVをダウンロードし、次のステップで使います。

### ステップ1: データをアップロードして全体像を把握する

CSV/Excelファイルをアップロードし、まずデータの全体像を把握しましょう。

```
プロンプト例（ファイルを添付して）:
「このデータの概要を教えてください。
- データの行数と列数
- 各列の説明
- 基本統計（合計、平均、最大値、最小値）
- データに欠損値や異常値はあるか」
```

### ステップ2: 気になるポイントを深掘りする

全体像を把握したら、気になるポイントを自然言語で質問していきます。

```
プロンプト例:
「5店舗の中で、最も売上が安定している店舗はどこですか？
変動係数を使って比較してください」

「売上が前月比10%以上落ちた月はありますか？
あれば、その原因の仮説を挙げてください」

「季節ごとの売上傾向を教えてください。
春夏秋冬で売上パターンに違いはありますか？」
```

### ステップ3: 分析結果をグラフで可視化する

最後に、分析結果を視覚的にまとめます。

```
プロンプト例:
「以下のグラフを作ってください。
1. 店舗別の年間売上合計（横棒グラフ）
2. 全店舗合計の月次推移（折れ線グラフ）
3. 最も売上の高い店舗と低い店舗の月次比較」
```

生成されたグラフは、Artifactウィンドウに表示されます。画像としてダウンロードし、社内報告書やプレゼン資料に活用しましょう。

ここまでの一連の流れ---データアップロード、全体把握、深掘り分析、グラフ化---は、あらゆるデータ分析業務の基本パターンです。Excelの関数やピボットテーブルの操作方法を覚えなくても、日本語で質問するだけで同じ結果が得られます。


## 5.8 コラム: Excel関数を覚えなくていい時代

VLOOKUP。IF関数。SUMIFS。COUNTIFS。INDEX-MATCH。これらの名前を聞いただけで、胃が痛くなる方もいるかもしれません。Excel関数はビジネスパーソンの必須スキルとされてきましたが、正直に言って、その学習コストは小さくありません。

「=VLOOKUP(A2, Sheet2!A:C, 3, FALSE)」。この文字列が何をしているか、パッと理解できる人はどれくらいいるでしょうか。VLOOKUPの引数の順序を覚え、FALSEとTRUEの違いを把握し、列番号を正しく数えて...。1つのミスで #N/A が返ってきて、デバッグに30分。こうした経験は、多くのビジネスパーソンに心当たりがあるはずです。

Claudeの時代、こうした苦労は過去のものになりつつあります。Claude in Excelに「A列の商品名で、シート2の価格表から単価を引っ張ってきて」と伝えるだけで、適切な数式が自動的に入力されます。チャット画面にExcelファイルをアップロードして「この数式が何をしているか教えて」と聞けば、日本語で丁寧に解説してくれます。

ただし、「関数を覚える必要がなくなった」ことと、「データの意味を理解しなくてよい」ことは別です。「前年比を計算して」と依頼するためには、前年比という概念を理解している必要があります。Claudeは計算の道具を使いこなしてくれますが、「何を計算すべきか」を決めるのはあなたです。

つまり、これからのExcelスキルとは「関数の書き方」ではなく「何を分析したいかを明確に言語化する力」です。良い質問ができる人が、良い分析結果を得る。この原則は、AIの時代になっても変わりません。


## 5.9 まとめ

この章では、Claudeのファイル連携機能とClaude in Excelアドインを使って、手元のデータをAIで分析・可視化する方法を学びました。

- **ファイルアップロードの基本**: PDF、DOCX、XLSX、CSV、画像など幅広い形式に対応。1ファイル30MB、1チャットに最大20ファイルまで
- **PDF分析**: 100ページ以下ならテキスト+ビジュアルの両方を分析可能。要約、比較分析、データ抽出の3パターン
- **CSV/Excel分析**: アップロードして日本語で質問するだけ。グラフ生成もチャット内で完結
- **画像の読み取り**: 名刺のテキスト化、グラフ画像の数値読み取り、ホワイトボードの構造化
- **Claude in Excel**: Excelのアドインとして動作し、自然言語でデータ分析、数式作成、グラフ作成、条件付き書式、エラー修正が可能。Pro、Max、Team、Enterpriseプランで利用可能（ベータ版）。マクロ・VBA・データテーブルは非対応
- **変換フロー**: PDF → Excel → PowerPoint の一気通貫で、会議資料の準備時間を大幅短縮
- **Projectsとの使い分け**: 常時参照する資料はProjectsに、一時的な分析データはチャットに直接アップロード

前章のArtifactsが「ゼロから成果物を作る」機能だったのに対し、この章のファイル連携は「既存のデータから価値を引き出す」機能です。両方を使いこなすことで、入力（データの分析）と出力（成果物の生成）の両面からClaudeを活用できるようになります。
