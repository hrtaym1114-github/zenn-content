# 第10章: 企画・アイデア発想術 --- AIブレインストーミング

新サービスの企画会議が来週に迫っている。デスクに向かい、白紙のノートを開く。「何か斬新なアイデアを出さなければ」と意気込むものの、浮かぶのは以前と似たような発想ばかり。ネットで事例を調べても、すでに誰かがやっていることの焼き直しにしかならない。気がつけば2時間が過ぎ、ノートには取り消し線だらけのメモが数行---。

1人でアイデアを考える作業には、構造的な限界があります。自分の経験や知識の範囲内でしか発想できず、同じ思考パターンをぐるぐると回ってしまう。心理学ではこれを「機能的固定」と呼びます。慣れ親しんだ枠組みから抜け出せない状態です。

前章ではメール・コミュニケーションの効率化を学びました。この章ではさらに一歩進んで、**「アイデアを生み出す」場面**にClaudeを活用します。第7章のドキュメント作成は「決まった内容を文書にする」作業でしたが、この章は**「まだ何も決まっていない段階」で思考を広げる**方法です。Claudeを「思考の壁打ち相手」にすることで、1人では辿り着けなかった切り口やアイデアに出会えるようになります。


## 10.1 1人ブレストの限界 --- なぜアイデアは堂々巡りするのか

ブレインストーミングは本来、複数人で行うことを前提に設計された手法です。1人で実施すると、3つの壁にぶつかります。

**壁1: 知識の偏り**。自分の業界・職種の知識に依存するため、異なる分野からの着想が生まれにくい。製造業の人は製造業の事例ばかり思い浮かび、IT業界の成功パターンを応用する発想が出てきません。

**壁2: 自己検閲**。「これは無理だろう」「こんなアイデアを言ったら笑われる」と、思いついた瞬間に自分で否定してしまう。ブレストの鉄則である「批判を保留する」が、1人では難しいのです。

**壁3: 視点の固定化**。顧客視点で考えようとしても、結局は自分の立場からの推測になる。競合の視点、投資家の視点、エンドユーザーの視点---立場を切り替えるのは想像以上に困難です。

Claudeをブレストの相手にすると、この3つの壁を突破できます。Claudeは多様な分野の知識を横断的に持っています。「くだらない」と思えるアイデアも否定せず展開してくれます。そして「顧客の視点で」「投資家の視点で」と指示すれば、本当にその立場から意見を述べてくれます。

では、具体的にどうやってClaudeとブレストするのか。3つのパターンを順番に見ていきましょう。


## 10.2 ブレスト3パターン --- 発散・深掘り・批判的検証

Claudeとのブレインストーミングは、**発散 → 深掘り → 批判的検証**という3つのステップで進めるのが効果的です。第6章で学んだ「段階的に進める」原則の応用です。一度にすべてを求めるのではなく、フェーズを分けて進めることで、アイデアの質が格段に上がります。

### パターン1: 発散 --- まず選択肢を広げる

最初のステップは「とにかく数を出す」ことです。質より量を重視し、思考の幅を広げます。

```
当社は従業員50名の中堅Web制作会社です。
既存のWeb制作事業に加えて、新しい収益の柱となるサービスを
検討しています。

以下の条件で、新規サービスのアイデアを10個出してください。

<条件>
- 既存のWeb制作スキル（デザイン・コーディング・マーケティング）を活かせる
- 初期投資は500万円以内で始められる
- BtoB向け
- まったく異なる切り口で10個（似たようなアイデアは不要）
</条件>

各アイデアは以下の形式で簡潔に:
- アイデア名（10字以内）
- 概要（50字以内）
- 既存スキルとの接続点（一言で）
```

このプロンプトのポイントは3つあります。まず、「まったく異なる切り口で」と明示すること。これを書かないと、「Webサイトリニューアルサービス」「LP制作代行」のように似た提案が並びがちです。次に、数を指定すること。「10個」と言えば、Claudeは後半のアイデアほど意外な方向に振ってくれます。そして、形式を指定すること。簡潔な形式にすることで、この段階では概要だけを俯瞰できます。

Claudeからは、たとえば「AIチャットボット構築」「社内研修動画制作」「Webアクセシビリティ監査」「ノーコードアプリ開発支援」「中小企業向けDXコンサル」といった、さまざまな方向のアイデアが返ってきます。自分1人では思いつかなかった切り口が必ず含まれているはずです。

:::message
**発散フェーズのコツ**: この段階では「これは無理だな」と思うアイデアも切り捨てないでください。一見非現実的に見えるアイデアが、次の深掘りフェーズで意外な可能性を見せることがあります。まずは選択肢を「テーブルに並べる」ことが大切です。
:::

### パターン2: 深掘り --- 気になるアイデアを分析する

発散で出たアイデアの中から、気になるものを選んで深掘りします。

```
先ほどのアイデアのうち、「Webアクセシビリティ監査サービス」を
詳しく分析してください。

<分析の観点>
1. 市場性: ニーズの大きさ、成長トレンド、ターゲット企業の規模感
2. 競合状況: 既存プレイヤーと差別化の余地
3. メリット: 当社にとっての強み・利点を3つ
4. デメリット・リスク: 考慮すべき課題を3つ
5. 実現可能性: 既存リソースで始められるか、追加で必要なもの
6. 収益モデル: 想定される料金体系と月額売上目標
7. 最初の一歩: 明日から着手できる具体的なアクション3つ
</分析の観点>
```

「その中で3番を詳しく」のような曖昧な指示でも通じますが、第6章の原則1（具体的に伝える）を活かして分析の観点を明示するほうが、実用的な回答が返ってきます。特に「最初の一歩」を聞くのがおすすめです。どんなに良いアイデアでも、次のアクションが見えなければ企画は前に進みません。

深掘りの結果を見て「これはいける」と感じたら、次のステップに進みます。「やっぱり違うな」と思ったら、別のアイデアを深掘りしましょう。この「選ぶ」判断こそが、人間の仕事です。

### パターン3: 批判的検証 --- あえて反対意見をぶつける

アイデアに熱中すると、都合の良い情報ばかり集めてしまいがちです。そこで、Claudeに「反対派」の役割を担ってもらいます。

```
あなたは事業投資の審査が厳しいことで知られるベテラン経営コンサルタントです。

当社が「Webアクセシビリティ監査サービス」を新規事業として
立ち上げようとしています。この案に対して、以下の観点で
厳しく批判してください。

<批判の観点>
1. この事業が失敗する理由を5つ挙げてください
2. ターゲット顧客が「お金を払わない」理由を3つ挙げてください
3. 3年後にこの事業が消えている最悪のシナリオを描いてください
4. 「それでもやるなら」最低限クリアすべき条件を3つ挙げてください
</批判の観点>

お世辞や励ましは不要です。率直に、厳しく評価してください。
```

第6章の原則3（役割を与える）を使い、「厳しいコンサルタント」という具体的な役割を設定しています。さらに「お世辞や励ましは不要です」と明記するのがポイントです。Claudeは基本的に協力的な姿勢で回答するため、この一言がないと批判が甘くなる傾向があります。

批判的検証で出てきた懸念点に対して、1つずつ対策を考えることで、企画の穴を事前に埋められます。社内のプレゼンで「その点は検討済みです」と答えられるようになるのです。

### 3パターンの流れ

```
  発散              深掘り            批判的検証
┌──────────┐    ┌──────────┐    ┌──────────┐
│ アイデア1 │    │          │    │          │
│ アイデア2 │    │ 市場性   │    │ 失敗理由 │
│ アイデア3 │──→│ 競合状況 │──→│ 反対意見 │
│  ...      │選ぶ│ メリット │検証 │ 最悪想定 │
│ アイデア10│    │ リスク   │    │ 必須条件 │
└──────────┘    └──────────┘    └──────────┘
  量を出す        質を深める       穴を見つける
```

この3ステップは、1回のチャットの中で連続して行えます。Claudeは会話の文脈を保持しているので、「先ほどの分析結果を踏まえて、反対意見を出してください」と続けるだけで、一貫した流れでブレストが進みます。


## 10.3 ビジネスフレームワークとの組み合わせ

ブレスト3パターンの基本を押さえたら、ビジネスの定番フレームワークとClaudeを組み合わせてみましょう。フレームワークは「考える枠組み」を提供し、Claudeはその枠を埋める具体的なアイデアを生成します。人間が枠を選び、AIが中身を埋める。この組み合わせが強力です。

### SWOT分析をClaudeと実施する

最も汎用性が高いのがSWOT分析です。自社の強み・弱み・機会・脅威を整理するフレームワークですが、1人でやると「強み」ばかり多くなりがちです。

```
以下の情報をもとに、当社のSWOT分析を行ってください。

<当社情報>
- 業種: 中堅Web制作会社（従業員50名）
- 強み: デザイン力に定評、大手クライアント3社と長期契約
- 弱み: 営業力が弱く新規開拓が苦手、技術スタックが古め
- 売上: 年商3億円（横ばい3年目）
- 最近の変化: 生成AIの台頭でクライアントから「AIを使った提案」を
  求められる機会が増加
</当社情報>

<出力形式>
各項目5つずつ挙げてください。
特に「脅威」と「弱み」は甘くならないよう、厳しめに分析してください。
分析後、SWOT のクロス分析（強み×機会、弱み×脅威など）から
具体的な戦略を3つ提案してください。
</出力形式>
```

ポイントは「甘くならないよう、厳しめに分析してください」という一言です。また、SWOTの4象限を出すだけでなく、**クロス分析から戦略を導出する**ところまで依頼するのが実務で役立つコツです。

### 5 Whys分析で問題の根本原因を探る

「なぜ」を5回繰り返して問題の根本原因を探る手法です。1人でやると3回目あたりで行き詰まりがちですが、Claudeと対話形式で進めると深い分析ができます。

```
以下の問題について、5 Whys分析を実施してください。

<問題>
当社のWebサイトからの問い合わせ件数が、
3か月前と比べて40%減少している
</問題>

「なぜ?」を5回掘り下げ、各段階で考えられる原因を
2〜3個ずつ挙げてください。
最後に、根本原因に対する具体的な改善策を提案してください。
```

Claudeは各段階で複数の「なぜ」を分岐させてくれるので、1つの原因に固執せず多角的に分析できます。「問い合わせが減った → SEO順位が下がった → 競合が増えた」という流れと、「問い合わせが減った → フォームが使いにくい → スマホ対応が不十分」という流れが同時に見えてくるのです。

### 新規事業のマトリクス生成

新規事業のアイデア出しでは、「市場 x 技術 x ニーズ」のマトリクスが有効です。

```
新規事業のアイデアを、マトリクス形式で整理してください。

<軸の定義>
- 横軸（市場セグメント）: 製造業 / 小売業 / 医療・介護 / 教育
- 縦軸（当社の強み）: デザイン力 / 技術力 / 顧客基盤 / 業界知見
</軸の定義>

各セルに、その組み合わせから生まれる具体的な
サービスアイデアを1つずつ記入してください。
計16個のアイデアを、表形式で出力してください。
特に有望だと思うものには★を付けてください。
```

16個のアイデアが一覧で出てくるので、自分では思いつかなかった「軸の交差点」を発見できます。たとえば「デザイン力 x 医療・介護」という組み合わせから、「高齢者向けWebサイトのアクセシビリティ改善サービス」が浮かぶかもしれません。


## 10.4 マーケティング戦略をClaudeと設計する

ブレストの3パターンとフレームワークを使いこなせるようになったら、マーケティング戦略の立案にも応用しましょう。ここでは、ペルソナ設計からコンテンツカレンダーまで、一連の流れをClaudeと進める方法を紹介します。

### ペルソナ設計

```
以下の情報から、ターゲットのペルソナを3パターン作成してください。

<サービス情報>
中小企業向けWebアクセシビリティ監査サービス
月額5万円〜、初回無料診断あり
</サービス情報>

<ペルソナの要素>
各ペルソナについて、以下を具体的に記述してください。
- 名前、年齢、役職
- 会社の規模と業種
- 1日の業務スケジュール（簡潔に）
- 抱えている課題と不満
- 情報収集の方法（どのメディアを見るか）
- サービス導入の決め手になりそうなポイント
- 導入を躊躇する理由
</ペルソナの要素>
```

ペルソナが出来上がったら、そのままClaudeに続けて依頼します。

### カスタマージャーニーと施策案

```
ペルソナ1（先ほどの田中課長）のカスタマージャーニーを
以下のフェーズで設計してください。

フェーズ: 認知 → 興味 → 検討 → 導入 → 定着

各フェーズで:
- 田中課長の行動
- 田中課長の心理（考えていること・不安）
- 当社が提供すべきコンテンツや施策
- KPI（測定指標）

を表形式で整理してください。
```

### コンテンツカレンダーの生成

```
上記のカスタマージャーニーを踏まえて、
「認知」と「興味」フェーズに注力した
3か月間のコンテンツカレンダーを作成してください。

<条件>
- ブログ記事: 月4本
- SNS投稿（X / LinkedIn）: 週3回
- メルマガ: 月2回
- 各コンテンツにタイトル案とターゲットフェーズを明記
- 記事の優先順位（高/中/低）も付けてください
</条件>

月ごとのテーマを設定し、テーマに沿った一貫性のある
コンテンツ計画にしてください。
```

ペルソナ設計 → カスタマージャーニー → コンテンツカレンダーという一連の流れを、1つのチャットで完結できます。この「段階的に進める」アプローチは、第6章の原則5そのものです。各ステップの出力を確認し、方向修正しながら進めることで、机上の空論ではない実用的なマーケティング計画が出来上がります。


## 10.5 Projectsで「ブレスト部屋」を作る

ここまでのブレストを1回きりで終わらせるのはもったいないことです。第3章で学んだProjectsを活用して、**「ブレスト部屋」**を作りましょう。アイデアを蓄積し、過去の議論を踏まえた発展的な思考が可能になります。

### 設定例

**プロジェクト名**: 新規事業ブレスト

**ナレッジベースに登録する資料**:
- 会社概要（事業内容、強み、リソース）
- 過去の企画書（成功例・失敗例）
- 市場調査レポート
- 競合分析資料

**カスタムインストラクション**:

```
あなたは新規事業開発のブレインストーミングパートナーです。

当社情報:
- 株式会社ABCクリエイティブ（Web制作会社、従業員50名）
- 年商3億円、主要顧客は大手メーカー3社
- 強み: デザイン力、UI/UX設計
- 課題: 新規開拓が弱い、Web制作単価の下落

ブレストのルール:
- アイデアは否定せず、まず発展させてから課題を指摘する
- 異業種の事例も積極的に取り入れる
- 毎回のセッション冒頭で「前回までのアイデア一覧」を提示する
- 具体的な数字（市場規模、想定売上）を可能な限り含める
- 最後に必ず「次に検討すべきこと」を提案する
```

この設定のポイントは「毎回のセッション冒頭で前回までのアイデア一覧を提示する」というルールです。Projectsのナレッジベースに過去のブレスト結果をテキストファイルとして追加していけば、Claudeは過去の議論を踏まえた上で新しいアイデアを出してくれます。

### ブレスト部屋の育て方

1. **初回**: 発散フェーズで10個のアイデアを出す。結果をテキストファイルにしてナレッジに追加
2. **2回目**: 前回のアイデアから3つを深掘り。分析結果もナレッジに追加
3. **3回目**: 深掘りしたアイデアに対して批判的検証。懸念点と対策をナレッジに追加
4. **4回目以降**: 新しい情報（市場ニュース、顧客の声など）を追加しながら、アイデアを発展

回を重ねるごとに「ブレスト部屋」の知識が厚くなり、Claudeの提案の質も上がっていきます。1人で考えているのに、まるで「チームで議論を重ねている」ような蓄積効果が得られるのです。

:::message
**チームでの活用**: Teamプランを利用すれば、このブレスト部屋をチームメンバーと共有できます。メンバーがそれぞれのセッションで追加したアイデアや分析結果が蓄積され、非同期でブレストを進められます。「会議室に集まらなくてもブレストできる」環境の実現です。
:::


## 10.6 ハンズオン: 自分の業務課題でClaudeブレストを実践

ここまでの内容を実践してみましょう。所要時間は15分程度です。

### お題

あなたが今、仕事で抱えている課題を1つ選んでください。以下のどれかに近いものが取り組みやすいです。

- 新しいサービスや商品のアイデアが欲しい
- 売上が伸び悩んでいて打開策を探している
- 業務効率化の方法を考えたい
- 部署のマーケティング施策を検討中

手元に適切な課題がない場合は、「自社のSNS運用を改善するアイデア」をテーマにしてください。

### 実践手順

**ステップ1: 発散（5分）**

claude.aiで新しいチャットを開き、以下の形式で依頼してください。

```
[あなたの課題を1〜2文で説明]

この課題に対して、まったく異なる切り口で解決策のアイデアを
10個出してください。
実現可能性は気にせず、ユニークなものを優先してください。

各アイデアは以下の形式で:
- アイデア名
- 概要（50字以内）
```

**ステップ2: 深掘り（5分）**

10個のアイデアの中から、直感で「面白い」と感じたものを1つ選びます。

```
[番号]のアイデアを詳しく分析してください。

- メリット3つ
- デメリット・リスク3つ
- 実現に必要なリソース（人・金・時間）
- 明日から始められる最初の一歩
```

**ステップ3: 批判的検証（5分）**

```
このアイデアに対して、厳しい上司の視点で反対意見を5つ挙げてください。
その後、各反対意見への反論も考えてください。
```

3つのステップを終えたとき、手元にはどんな情報が揃っているでしょうか。10個の選択肢、1つの詳細分析、5つの懸念点とその対策。1人で白紙のノートに向かっていた15分間とは、まったく異なる成果が得られているはずです。


## 10.7 コラム: AIは創造性を奪うか?

:::message
**コラム: AIは創造性を奪うか?**

「AIにアイデアを出してもらうなんて、自分で考える力が衰えるのでは？」

この不安を抱く方は少なくありません。クリエイティブな仕事に携わる方ほど、この問いを真剣に考えるでしょう。

結論から言えば、**AIは「選択肢」を広げるツールであり、「選択」をするのは人間**です。

たとえ話で考えてみましょう。画家は絵の具の色数が増えたからといって、創造性を失ったでしょうか。建築家はCADソフトを使うようになって、設計力が衰えたでしょうか。むしろ逆です。道具が進化するたびに、人間はより大きな創造にエネルギーを注げるようになりました。

Claudeとのブレストも同じです。Claudeが出す10個のアイデアの中から「これだ」と選ぶのは、あなた自身の判断力・直感・経験です。Claudeの分析結果を読んで「ここは違う」「ここを膨らませたい」と感じる感性も、あなた自身のものです。

実際のところ、AIを使いこなす人ほど「考える時間」は増えています。アイデアの「量産」という労働的な部分をAIに任せることで、「どのアイデアを選ぶか」「どう組み合わせるか」「本当に顧客に響くか」という、より高次の思考に集中できるようになるからです。

AIは創造性を奪いません。AIは**「創造のための材料」を大量に、瞬時に提供してくれるパートナー**です。その材料から何を作るかは、これまでと変わらず、あなたの創造性にかかっています。
:::


## 10.8 まとめ

この章では、Claudeを「思考の壁打ち相手」として活用し、企画力を拡張する方法を学びました。

- **1人ブレストの3つの壁**: 知識の偏り、自己検閲、視点の固定化。Claudeは多様な知識、批判の保留、視点の切り替えでこの壁を突破してくれる
- **ブレスト3パターン**: 発散（量を出す）→ 深掘り（質を深める）→ 批判的検証（穴を見つける）の3ステップで、アイデアの質と実現性を段階的に高める
- **ビジネスフレームワークとの組み合わせ**: SWOT分析、5 Whys分析、マトリクス生成など、定番フレームワークの枠をClaudeが埋めることで、1人でも構造的な分析が可能
- **マーケティング戦略の一気通貫設計**: ペルソナ設計 → カスタマージャーニー → コンテンツカレンダーを、1つのチャットで段階的に進められる
- **Projectsで「ブレスト部屋」を構築**: 過去のアイデアや分析結果を蓄積し、回を重ねるごとに思考の質が上がる仕組みを作る
- **AIと創造性の関係**: AIは選択肢を広げるツール。「何を選ぶか」という創造の核心は、人間の仕事のまま
