# 第12章: Cowork --- AIエージェントが変える未来の仕事

金曜の午後。経理担当のあなたは、デスクの上に積まれた今月の領収書の山を眺めてため息をつく。出張の交通費、接待の飲食代、備品の購入レシート。これを1枚ずつ確認し、Excelの経費精算表に転記し、カテゴリ別に集計する。毎月2時間以上かかるこの作業が、金曜の午後を憂鬱にする---。

もし、こんな指示を出すだけで済むとしたらどうでしょうか。

「デスクトップの『領収書_2026年1月』フォルダにある画像を全部読み取って、日付・金額・店名・カテゴリを抽出し、経費精算表をExcelで作成してください。カテゴリ別の合計も入れてください」

これを実現するのが、AnthropicがリリースしたClaude **Cowork**（コワーク）です。AIが指示を受け取り、計画を立て、ファイルを読み書きし、成果物を生成する。いわば、**PCの中で仕事をしてくれるAIエージェント**です。

この章では、Coworkの概念と仕組みを理解し、ビジネスでどのような可能性があるのかを具体的なシナリオとともに紹介します。2026年2月時点ではResearch Preview（研究プレビュー）の段階ですが、AIと仕事をする未来の形を先取りしておきましょう。


## 12.1 AIエージェントとは何か --- 「チャット」から「実行」へ

まず、「AIエージェント」という言葉の意味を整理しましょう。

ここまでの章で使ってきたClaudeは、基本的に**対話型AI**です。あなたが質問し、Claudeが答える。あなたが依頼し、Claudeが文章を生成する。この「あなたが指示を出す → Claudeが返答する」というサイクルが、1つ1つ繰り返されます。

AIエージェントは、このサイクルを大きく変えます。

**対話型AI**: 「この領収書の金額を読み取って」→ 回答 → 「次はこの領収書を...」→ 回答（1つずつ繰り返し）

**AIエージェント**: 「フォルダの領収書を全部処理して経費精算表を作って」→ 計画を立てる → 1枚ずつ自動で読み取る → Excelに転記する → 集計する → 完成ファイルを保存する

違いが伝わるでしょうか。対話型AIが「1回の指示に1回の応答」を返すのに対し、AIエージェントは**1つの指示から複数のステップを自律的に実行**します。人間に例えるなら、対話型AIは「1つ質問するたびに答えてくれる相談相手」で、AIエージェントは「仕事を丸ごと任せられるアシスタント」です。

```
┌──────────────────────────────────────────────────────┐
│              対話型AI vs AIエージェント                │
│                                                      │
│  【対話型AI（これまでのClaude）】                     │
│  ユーザー → 指示 → AI → 応答 → ユーザー → 指示 → …  │
│  （1回ずつ指示・応答を繰り返す）                     │
│                                                      │
│  【AIエージェント（Cowork）】                         │
│  ユーザー → 指示 → AI → 計画 → 実行1                 │
│                              → 実行2                 │
│                              → 実行3                 │
│                              → 成果物 → ユーザー     │
│  （1つの指示から自律的に複数ステップを実行）          │
└──────────────────────────────────────────────────────┘
```

2025年後半から2026年にかけて、この「AIエージェント」は業界全体のキーワードになっています。OpenAI、Google、Anthropicの各社が、それぞれのアプローチでエージェント機能を発表しています。Claudeにおけるエージェント機能が、Coworkです。


## 12.2 Claude Cowork の概要 --- デスクトップで動くAIアシスタント

### 何ができるのか

Coworkは、Claudeデスクトップアプリに内蔵されたエージェント機能です。2026年1月にResearch Previewとしてリリースされ、Pro、Max、Team、Enterpriseプランで利用できます。

最大の特徴は、**ローカルファイルに直接アクセスできること**です。これまでのclaude.aiでは、ファイルを分析してもらうために毎回アップロードする必要がありました。Coworkでは、あなたのPC上のフォルダを指定するだけで、その中のファイルを直接読み書きできます。

もう1つの特徴は、**サブエージェントによる並行処理**です。複雑なタスクを内部で複数の小さなタスクに分割し、並行して処理を進めます。100枚の領収書を1枚ずつ順番に処理するのではなく、複数のサブエージェントが同時に処理を進めるイメージです。

### 動作の流れ

Coworkでタスクを実行する流れは、次の6ステップです。

1. **指示を出す**: やりたいことを自然言語で伝える
2. **計画を確認する**: Claudeがアプローチを計画し、提示する
3. **承認する**: 計画に問題がなければ、承認して実行を開始する
4. **進捗を見守る**: 各ステップの推論と進捗がリアルタイムで表示される
5. **途中で軌道修正する（必要に応じて）**: 方向性がずれていれば、介入して修正できる
6. **成果物を受け取る**: 完成したファイルがPC上に直接保存される

注目すべきは、ステップ2と3です。Coworkは「いきなり実行」するのではなく、まず計画を見せてくれます。「フォルダ内の画像を読み取り、日付・金額・店名を抽出し、Excelファイルに整理します。よろしいですか？」と確認が入ります。この設計により、意図しない操作を防げます。

### 安全設計

Coworkには、いくつかの安全機構が組み込まれています。

- **ファイル削除時の許可確認**: ファイルを削除する操作には、必ずユーザーの明示的な許可が必要です
- **仮想マシン（VM）での隔離**: コードの実行は内蔵の仮想マシン内で行われ、システム全体に影響を与えません
- **フォルダ指定によるアクセス制限**: 指定したフォルダ内のファイルのみにアクセスします
- **途中停止**: いつでもユーザーが実行を停止できます

「AIにPCを操作させるなんて怖い」と感じるかもしれません。しかし、重要な操作には確認が入る設計になっているため、AIが勝手にファイルを消したり、意図しないフォルダにアクセスしたりすることは防がれています。


## 12.3 ビジネスでの可能性 --- 4つの実例シナリオ

Coworkの仕組みを理解したところで、具体的なビジネスシーンでどう使えるのかを見てみましょう。以下の4つのシナリオは、いずれもCoworkが得意とする「ファイル操作 + 知識処理」の組み合わせです。

### シナリオ1: レシート画像から経費精算表を自動生成

冒頭で紹介したシナリオを、もう少し詳しく見てみましょう。

**従来のやり方**:
1. レシートを1枚ずつ目視で確認する
2. 日付、金額、店名をExcelに手入力する
3. カテゴリ（交通費、接待費、消耗品費など）を判断して記入する
4. カテゴリ別の集計を行う
5. 所要時間: 約2時間（レシート50枚の場合）

**Coworkに依頼する場合**:
「『領収書_2026年1月』フォルダにあるレシート画像をすべて読み取ってください。日付・金額・店名・推定カテゴリを抽出し、経費精算表をExcelで作成してください。カテゴリ別の小計と合計も含めてください」

Coworkは画像認識でレシートを読み取り、情報を抽出し、数式入りのExcelファイルを生成します。人間がやるべきことは、出力されたExcelの内容を確認し、カテゴリの分類ミスがないかチェックすることだけです。

### シナリオ2: 散らかったフォルダを顧客別に整理

営業部のファイルサーバーにある共有フォルダ。提案書、見積書、議事録、契約書が「日付_ファイル名」の形式でフラットに並んでいる。ファイル数は200を超え、必要な資料を探すたびに時間を浪費している---。

**Coworkへの指示例**:
「『営業資料』フォルダのファイルを分析し、顧客名ごとにサブフォルダを作って整理してください。各顧客フォルダの中は、提案書・見積書・議事録・契約書のカテゴリ別に分けてください。整理結果の一覧表もExcelで作成してください」

Coworkはファイル名と内容を分析して顧客名を特定し、フォルダ構造を作り、ファイルを移動（またはコピー）し、整理結果のレポートまで作成します。

### シナリオ3: 競合情報を収集して比較表を作成

新規プロジェクトの企画にあたり、競合3社のサービス内容を調査する必要がある。各社のWebサイトを巡回し、料金プラン、機能、導入事例を調べ、比較表にまとめたい。

**Coworkへの指示例**:
「以下の3社のWebサイトから、SaaSプロダクトの料金プラン・主要機能・導入事例を調査し、比較表をExcelで作成してください。URL: [A社] [B社] [C社]。比較表には、各社の強み・弱みの分析も追加してください」

Coworkはプラグインやツールを活用してWeb情報を収集できます。収集した情報を整理・分析し、比較表とともに「どの場面でどの競合が強いか」の分析レポートまで生成します。

### シナリオ4: 過去の議事録から今回のアジェンダ案を生成

定例会議の準備。過去3か月分の議事録（12ファイル）を振り返り、未完了のアクションアイテムを洗い出し、今回の議題案をまとめたい。

**Coworkへの指示例**:
「『定例会議_議事録』フォルダにある過去3か月分の議事録を全て読み込み、以下を作成してください。(1) 各回の要約一覧、(2) 未完了アクションアイテムの一覧、(3) 今回の定例会議のアジェンダ案。アジェンダ案はWordファイルで出力してください」

12個のファイルを自動で読み込み、横断的に分析してくれます。第8章で学んだ「情報整理術」の延長線上にありますが、Coworkではファイルのアップロードすら不要です。フォルダを指定するだけで、一連の作業が完了します。

:::message
**シナリオを読んで「本当にここまでできるの？」と思った方へ**: Coworkは2026年2月時点でResearch Previewの段階であり、すべてのシナリオが完璧に動作するとは限りません。ファイルの形式や内容によっては、期待どおりに処理できないケースもあります。ここで紹介したのは「可能性」として設計されている使い方です。正式版のリリースとともに、精度と安定性は向上していくでしょう。
:::


## 12.4 現状の制限と注意点 --- 正直に知っておくべきこと

Coworkの可能性に期待しつつも、現時点での制限は正確に把握しておくべきです。

### Research Previewであること

最も重要な点は、**Coworkは2026年2月時点でResearch Preview（研究プレビュー）**であるということです。正式版（GA: General Availability）ではありません。つまり、機能の変更、UIの変更、場合によっては一時的な提供停止もありえます。業務の中核プロセスをCoworkに完全に依存するのは、まだ時期尚早です。

### 対応環境の制限

| 項目 | 現状 | 今後の予定 |
|------|------|-----------|
| macOS | 対応（デスクトップアプリ） | Research Preview |
| Windows | 対応（デスクトップアプリ） | 2026年2月〜。arm64非サポート |
| Web（claude.ai） | 非対応 | 未定 |
| モバイル | 非対応 | 未定 |

macOSに加え、2026年2月からはWindows版もリリースされています（ただしarm64は非サポート）。

### 利用可能なプラン

公式ヘルプセンターの記載では、Pro、Max、Team、Enterpriseプランで利用可能とされています。Freeプランでは利用できません。

### 機能上の制限

- **セッション間のメモリなし**: 会話をまたいだ記憶を保持しません。前回のCoworkセッションで何をしたかは、次のセッションには引き継がれません
- **Projects内での利用不可**: 第3章で学んだProjectsの中ではCoworkを使えません。Projectsの知識ベースとCoworkを同時に活用することはできない状態です
- **デスクトップアプリ必須**: アプリを閉じるとセッションが終了します。長時間の処理中にアプリを閉じないよう注意が必要です
- **会話・Artifactsの共有不可**: Coworkセッションの結果を他のユーザーと直接共有する機能はありません

特に「Projectsとの併用不可」は、本書の読者にとって大きな制約でしょう。Projectsにアップロードした業務知識をCoworkで活用できれば理想的ですが、現時点ではそれぞれ独立した機能です。正式版での改善が期待されます。


## 12.5 競合との比較 --- ChatGPT agent、Google Workspace Studio

AIエージェントは、Claude Coworkだけの話ではありません。主要なAIサービスが、それぞれ独自のアプローチで開発を進めています。

| 項目 | Claude Cowork | ChatGPT agent（旧Operator） | Google Workspace Studio |
|------|--------------|--------------------------|------------------------|
| **提供元** | Anthropic | OpenAI | Google |
| **動作環境** | デスクトップアプリ | ChatGPT内（Web + デスクトップ） | Google Workspace連携 |
| **得意領域** | ローカルファイル操作、文書処理 | Web操作 + 情報分析 + ファイル操作 | Gmail、Drive、Sheets等の操作 |
| **アプローチ** | ファイルシステム + VM | ブラウザ操作 + Deep Research統合 | Google製品との深い統合 |
| **安全設計** | ファイル削除時の許可確認、VM隔離 | ユーザー確認ステップ | Googleアカウントの権限管理 |

3社のアプローチは明確に異なります。

**Claude Cowork**は「PCの中のファイル」を扱うことに特化しています。ローカルファイルへの直接アクセスと、文書処理・データ整理の精度が強みです。

**ChatGPT agent**は、かつて「Operator」として提供されていたWeb操作機能を、Deep Research（情報分析）やファイル操作機能と統合したものです。2025年7月にChatGPTに完全統合され、Web操作だけでなく多面的なタスクをこなせるようになっています。

**Google Workspace Studio**は「Google製品との統合」が最大の武器です。Geminiを搭載し、Gmail、Googleドライブ、Googleスプレッドシートなど、日常的に使うGoogleサービスをAIが横断的に操作します。サードパーティアプリ（Asana、Jira等）との連携も可能です。

どれが優れているかではなく、**自分の業務でどのタイプのタスクが多いか**で選ぶのが合理的です。ローカルファイルの処理が多いならCowork、Webサービスの操作や情報分析が多いならChatGPT agent、Google Workspaceが中心ならGoogle Workspace Studio。将来的には、これらを場面に応じて使い分ける時代が来るでしょう。


## 12.6 コラム: Claude Code との関係 --- 開発者とビジネスパーソンの分岐点

:::message
**コラム: Claude Code と Cowork --- 同じ思想、異なる対象**

本書はビジネスパーソン向けですので、Claude Code について詳しくは触れていません。しかし、CoworkとClaude Codeの関係を知っておくと、Anthropicの設計思想がよく見えてきます。

**Claude Code**は、ターミナル（コマンドライン）で動作する開発者向けのAIエージェントです。プログラマーが「この機能を実装して」と指示すると、コードを書き、テストを実行し、バグを修正する。一連の開発作業を自律的に進めます。

**Cowork**は、デスクトップアプリで動作するビジネスパーソン向けのAIエージェントです。「このフォルダのファイルを整理して」と指示すると、ファイルを読み、分類し、レポートを作成する。一連の事務作業を自律的に進めます。

両者の関係は、こう整理できます。

```
同じ設計思想: 「指示 → 計画 → 自律実行 → 成果物」

Claude Code（開発者向け）          Cowork（ビジネスパーソン向け）
├ 動作環境: ターミナル              ├ 動作環境: デスクトップアプリ
├ 対象: ソースコード               ├ 対象: ビジネス文書・データ
├ 操作: コード生成・テスト実行     ├ 操作: ファイル読み書き・整理
└ ユーザー: エンジニア             └ ユーザー: あらゆるビジネスパーソン
```

実は、Cowork自体がClaude Codeを使って約1.5週間で開発されたというエピソードもあります。AIエージェントがAIエージェントを作る---まさに未来の開発スタイルです。

次の第13章では、Claude Codeとこれからの働き方についてもう少し詳しく紹介します。「プログラミングはしないけれど、自動化には興味がある」という方にとっても、知っておく価値のある世界です。
:::


## 12.7 Coworkに備えて今からできること

Coworkの正式版リリースを待つ間に、今からできる準備があります。

**1. ファイル整理の習慣をつける**

Coworkはフォルダ単位でファイルにアクセスします。「デスクトップに何でも保存」の状態では、Coworkに的確な指示を出せません。業務カテゴリ別、プロジェクト別にフォルダを整理しておくと、Coworkの効果を最大限に引き出せます。

**2. 「タスクの言語化」を意識する**

Coworkへの指示は自然言語です。日頃から「自分がやっている作業を言葉で説明する」練習をしておくと、Coworkへの指示精度が上がります。第6章のプロンプト5原則---特に「具体的に伝える」と「段階的に進める」---は、そのままCoworkへの指示にも適用できます。

**3. Claudeデスクトップアプリをインストールしておく**

macOSユーザーの方は、Claudeのデスクトップアプリをインストールしておきましょう。Coworkが利用可能になった際に、すぐに試せます。アプリはAnthropic公式サイトからダウンロードできます。

**4. 「自動化したい作業リスト」を作る**

日常業務の中で「毎回同じ手順を繰り返している作業」をリストアップしておきましょう。それがCoworkに任せる候補になります。経費精算、レポート作成、データ集計、ファイル整理。繰り返し作業ほど、Coworkの恩恵は大きくなります。


## 12.8 まとめ

この章では、Claude Coworkの概念と可能性、そして現状の制限について学びました。

- **AIエージェントとは**: 対話型AIが「1回の指示に1回の応答」なのに対し、AIエージェントは「1つの指示から複数ステップを自律的に実行」する。Coworkは、PCの中で仕事をしてくれるAIアシスタント
- **Coworkの特徴**: ローカルファイルへの直接アクセス、サブエージェントによる並行処理、計画提示と承認による安全設計。ファイルのアップロード/ダウンロードが不要になる
- **ビジネスシナリオ**: 経費精算の自動化、フォルダの顧客別整理、競合情報の収集と比較表作成、議事録群からのアジェンダ生成。いずれも「ファイル操作 + 知識処理」の組み合わせ
- **現状の制限**: Research Preview段階であること、セッション間メモリなし、Projects内での利用不可。業務の中核プロセスへの完全依存は時期尚早
- **競合比較**: Cowork（ローカルファイル）、ChatGPT agent（Web操作 + 情報分析）、Google Workspace Studio（Google連携）。得意領域が異なり、業務に応じた使い分けが合理的
- **今からの準備**: ファイル整理、タスクの言語化、デスクトップアプリのインストール、自動化したい作業リストの作成

AIエージェントの登場は、「AIに質問する」から「AIに仕事を任せる」への転換点です。まだ黎明期ではありますが、この流れは確実に加速していきます。今のうちにCoworkの概念を理解し、準備を整えておくことで、正式版がリリースされた日から、すぐに「AIと共に働く」スタイルを始められるでしょう。
