# 第13章: さらに先へ --- Claude Code とAIネイティブな働き方

ここまで12の章を通じて、Claudeとの仕事術を学んできました。アカウント作成から始まり、Projects、Artifacts、プロンプトの5原則、業務別ワークフロー、チーム導入、そしてCoworkまで。すでにあなたの働き方は、本書を手に取る前とは大きく変わっているはずです。

しかし、AIの進化は止まりません。この最終章では、あなたの視界をさらに広げます。「AIを使う」から「AIと共に働く」へ。その先にある、AIネイティブな働き方の姿を一緒に見ていきましょう。


## 13.1 「AIを使う」から「AIと共に働く」へ

本書で紹介してきた使い方を振り返ると、1つの変化に気づきます。

第1章ではClaudeに質問を投げかけ、答えを受け取る「一問一答」から始めました。第6章でプロンプトの5原則を学び、対話の質が上がりました。第3章のProjectsで自社の知識を持った専用AIを構築し、第12章のCoworkではPCの中の作業を丸ごと任せるようになりました。

この変化を一言で表すなら、こうなります。

```
道具として使う → パートナーとして働く

Ch1-6:  人間が指示 → AIが回答 → 人間が判断
Ch7-10: 人間が方針 → AIがドラフト → 人間が仕上げ
Ch11:   チームがルール → AIがインフラに
Ch12:   人間が目標 → AIが自律的に作業 → 人間が確認
```

「AIネイティブな働き方」とは、AIを特別なツールとして意識するのではなく、仕事の自然な一部として組み込むスタイルです。電卓やメールソフトを「使っている」と意識しないように、AIとの協働が当たり前になる。それが、これからの仕事のスタンダードです。

この流れの先に、もう1つ知っておきたいツールがあります。


## 13.2 Claude Code --- ターミナルで動くAI

**Claude Code**は、パソコンの「ターミナル」（黒い画面）で動くAIアシスタントです。プログラマー向けのツールに聞こえるかもしれません。しかし、非エンジニアのビジネスパーソンにも知っておく価値があります。

### Claude Code でできること

Claude Codeは、パソコン上のファイルやフォルダに直接アクセスし、自律的に作業を進めます。Coworkがデスクトップアプリ上で動くのに対して、Claude Codeはターミナル（コマンドライン）から操作します。

具体的な活用例を挙げましょう。

- **複雑な自動化**: 「毎週月曜日にこのフォルダのCSVを集計してレポートを作成して」
- **ファイルの一括処理**: 「100個のPDFファイルから特定の情報を抽出してExcelにまとめて」
- **Webサイトの構築**: 「この企画書の内容で、社内向けの情報共有サイトを作って」
- **データ分析の自動化**: 「売上データを読み込んでグラフを作り、傾向をレポートにまとめて」

注目すべきは、これらの作業を「コードを書けない人」でも日本語の指示だけで実行できる点です。Claude Codeが必要なプログラムを自動で書き、実行し、結果を返してくれます。

### この本自体がClaude Codeで作られている

実は、今あなたが読んでいるこの本自体が、Claude Codeを活用した出版システムで制作されています。

著者である私（ayumu）は、Claude Codeの「エージェントシステム」を構築しました。企画編集者、リサーチャー、著者、校閲者、組版担当など、出版社の各役割をAIエージェントとして定義し、パイプラインを組んでいます。

```
AI出版システムの流れ:

  企画 → リサーチ → 構成案 → 執筆 → 編集 → 校閲 → 組版
  │       │        │       │      │      │      │
  企画    リサーチ   構成    著者   編集   校閲   組版
  編集者  エージェント 編集者  エージェント 者  者   担当
  (AI)   (AI)     (AI)   (AI)   (AI)  (AI)  (AI)
                                              │
                    人間（ayumu）= 品質チェック・最終判断
```

もちろん、すべてをAIに丸投げしているわけではありません。企画の承認、構成案の確認、最終原稿の品質チェックは人間が行っています。しかし、リサーチの実施、原稿のドラフト執筆、校正作業、事実確認、組版といった膨大な作業をAIエージェントが担当しています。

1人で出版社を運営する。そんなことが現実になる時代が来ています。

:::message
**Claude Code に興味が湧いたら**: Claude Codeは現在、Anthropic公式サイトからインストールできます。プログラミング経験がなくても、日本語で指示を出すだけで使い始められます。まずはClaude Codeの公式ドキュメント（docs.anthropic.com）を覗いてみてください。ターミナルの基本操作さえ覚えれば、あなたの仕事の自動化の可能性が一気に広がります。
:::


## 13.3 複数AIの使い分け術

本書ではClaudeに焦点を当ててきました。しかし、AIネイティブな働き方では、複数のAIを組み合わせることでさらに効果が高まります。第1章で触れた「使い分け」の考え方を、もう一歩進めましょう。

### Claude + Perplexity: 調査の精度と速度を最大化

**Perplexity**は、AI搭載の検索エンジンです。Web上の最新情報をリアルタイムで検索し、出典付きで回答を返してくれます。

活用の流れはこうです。

1. **Perplexityで最新情報を収集**: 「2026年のSaaS市場の最新トレンドは？」
2. **Claudeで分析・構造化**: Perplexityの検索結果をClaudeに渡し、「この情報をもとに競合分析レポートを作成して」

Claudeは2026年2月時点の訓練データに基づいて回答します。リアルタイムの情報が必要な場面では、Perplexityで最新データを集め、Claudeで深い分析を行う。この組み合わせが効果的です。

具体的な連携プロンプトを紹介しましょう。Perplexityで集めた情報をClaudeに渡す際のテンプレートです。

```
以下はPerplexityで収集した最新の市場情報です。
この情報をもとに、指定した形式でレポートを作成してください。

<収集データ>
（Perplexityの検索結果をここに貼り付け）
</収集データ>

<レポートの条件>
- 目的: [誰に/何のために使うか]
- 構成: (1)市場概況 (2)主要トレンド3つ (3)自社への示唆
- 分量: [A4で何ページ]
- 注意: 収集データに含まれない情報は「要追加調査」と注記してください
</レポートの条件>
```

ポイントは最後の「収集データに含まれない情報は注記してください」という一文です。これにより、Claudeが訓練データで補完した情報と、Perplexityで裏取りされた情報を区別できます。

### Claude + NotebookLM: 大量資料の一括処理

Googleの**NotebookLM**は、アップロードした資料だけを情報源として回答するツールです。外部知識を混ぜず、あなたの資料に忠実に答えてくれる点が特徴です。

Claudeとの使い分けはこうなります。

| 場面 | 向いているツール |
|------|----------------|
| 資料の内容を正確に確認したい | NotebookLM |
| 資料をもとに新しい文書を作りたい | Claude（Projects） |
| 資料の内容をポッドキャスト形式で聞きたい | NotebookLM |
| 資料を踏まえて企画を発想したい | Claude |

NotebookLMは「理解」に、Claudeは「生成」に強みがあります。大量の資料をまずNotebookLMで整理し、その要約をClaudeに渡して文書を作成する。この連携で、情報の精度と成果物の質を両立できます。

### Claude + ChatGPT: それぞれの得意分野で併用

第1章で比較したとおり、ClaudeとChatGPTには明確な得意分野の違いがあります。両方を契約している方は、場面に応じて切り替えましょう。

```
Claude を選ぶ場面              ChatGPT を選ぶ場面
───────────────               ────────────────
長文の報告書を分析する           プレゼン用の画像を生成する
フォーマルな文書を作成する        音声で対話しながら考える
大量資料をProjectsで管理する     外部ツールとの連携が必要
正確さ・安全性が求められる       創造的なアイデア出し
```

重要なのは、「どちらが上か」ではなく「今の作業にはどちらが合うか」を判断する習慣を持つことです。これが、AIネイティブな働き方の基本姿勢です。

:::message
**複数AI活用の第一歩**: まずはClaudeをメインに据え、足りない部分を他のAIで補う形が始めやすいでしょう。Perplexityは無料プランでも十分使えますし、NotebookLMもGoogleアカウントがあれば無料で利用できます。
:::


## 13.4 2026年以降の展望 --- 「作業」から「判断」へ

最後に、これからの仕事がどう変わっていくのかを考えてみましょう。

### AIエージェントの普及がもたらす変化

第12章で紹介したCoworkは、AIエージェントの幕開けを象徴するプロダクトです。2026年後半以降、AIエージェントはさらに進化し、普及していくでしょう。

この変化が意味することは明確です。「作業」の多くをAIが担当するようになり、人間の役割は「判断」にシフトしていきます。

```
これまで                    これから
────────                   ────────
人間: 作業 + 判断            人間: 判断 + 創造
                            AI:  作業 + 下準備

例:
報告書を「書く」作業        → AIが書く。人間は方針を決め、品質を判断する
データを「集めて整理する」  → AIが集める。人間は何を集めるか判断する
メールを「1通ずつ書く」    → AIが下書きする。人間はトーンと内容を判断する
```

### 「AIに奪われる仕事」ではなく「AIと共に進化する仕事」

AIの進化に不安を感じる方もいるかもしれません。「自分の仕事がなくなるのではないか」と。

しかし、本書を通じて実感されたのではないでしょうか。AIは、あなたの仕事を「奪う」のではなく「変える」のです。

報告書を書く仕事はなくなりません。ただし、「一から手書きで作る」から「AIのドラフトをもとに判断・修正する」に変わります。メール対応もなくなりません。ただし、「1通ずつ悩みながら書く」から「AIの提案をもとに素早く判断する」に変わります。

本書で学んだスキルは、まさにこの変化に対応するためのものです。Projectsで業務知識をAIに渡し、プロンプトの5原則で的確に指示を出し、Artifactsで成果物を素早く形にする。これらは、AIと共に働く時代の「基礎体力」です。

変化を恐れるのではなく、先に備える。本書を読み終えたあなたは、その準備ができています。


## 13.5 おわりに --- 今日から始める一歩

本書を最後まで読んでくださり、ありがとうございます。

全13章を通じて、Claudeとの仕事術を体系的にお伝えしてきました。最後に、今日からできる具体的な一歩を3つ提案させてください。

**一歩目: 明日の仕事を1つ、Claudeと一緒にやる**

大きなことを始める必要はありません。明日の朝、最初に取りかかる仕事を1つ選んでください。メールの返信でも、会議の準備でも構いません。その1つの仕事を、Claudeと一緒にやってみてください。第6章のプロンプト5原則を思い出しながら。

**二歩目: 自分専用のProjectsを1つ作る**

第3章で学んだProjectsを、あなたの業務に合わせて1つ設定してください。自社の製品資料、業務マニュアル、過去の成果物。何でもよいので、まず1つアップロードしてカスタムインストラクションを書く。それだけで、Claudeは「あなたの仕事を知っているAI」に変わります。

**三歩目: 隣の人にこの本の話をする**

第11章で触れたとおり、AI活用は個人で閉じていると効果が限定されます。隣の席の同僚に、「Claudeってこんな使い方ができるんだよ」と話してみてください。1人の「便利だ」が2人になり、やがてチーム全体に広がっていきます。
