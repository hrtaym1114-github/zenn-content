# 収益の現実──8ヶ月で3,385円

## 約束を果たす章

初版のCh.00で、私はこう書いた。

> マネタイズの試行錯誤と、現時点での収益（正直に書く）

初版では、正直に書くと言いながら**具体的な金額を書かなかった**。書けなかったのではない。書きたくなかった。当時の売上は2,000円で、それを本に書くのが恥ずかしかった。

この章はその約束を果たすために書いている。全部出す。

## 8ヶ月の全収益

2026年1月に運用を開始し、8月29日時点までの売上はこれで全部だ。

| 商品 | 価格 | 販売日 | 受取額 |
|------|------|--------|--------|
| 別の技術本 | ¥2,000 | 2026-05 | ¥1,736 |
| **本書（初版）** | ¥1,900 | 2026-07 | ¥1,649 |
| **合計** | | **2冊** | **¥3,385** |

240日で3,385円。月あたり423円。

そしてこれ以外の収益は**ゼロ**である。

| チャネル | 8ヶ月の収益 | 状態 |
|---------|-----------|------|
| Zenn Books | **¥3,385** | ✅ 唯一の収益源 |
| ブログ（AdSense・アフィリエイト） | ¥0 | 母数不足 |
| note | ¥0 | 有料記事の販売なし |
| X.com | ¥0 | 収益化条件に未到達 |
| 法人向けコンサル | ¥0 | 導線設置のみ、問い合わせ0件 |
| 個人開発ツール | ¥0 | 有料化に至らず |

5チャネルを運用し、84コマンドと28エージェントとGHA19本を動かして、**現金を生んだ経路は1本だけ**だった。

いま読んでいるこの本が、その1本である。

## いちばん高くついた間違い

数字より重要なのは、この8ヶ月で私が犯した**最大の判断ミス**のほうだ。

2026年5月31日、私はエージェント組織の顧問団（Advisory Board）11体を招集して、マネタイズ戦略を検証させた。複数の視点から敵対的に検討し、方針を確定した。決定事項のひとつがこれだ。

> **Zenn Books（10〜15時間の執筆）: 途中で止まる形状。90日間、着手禁止。**

理由は形状分析だった。過去に完走できなかったプロジェクトと同じ「重い・長い・完成まで報酬が無い」構造だから、また止まる、と。分析として筋は通っていた。

**ところがその判断を下した5月31日の時点で、私はZenn Booksを2冊すでに公開していた（5月16日・5月24日）。そして5月に1冊、実際に売れていた。**

つまり私は、**目の前で現金を生んでいた形式を、机上の形状判断で封印した**ことになる。

代わりに主軸に据えたのは「ブログの滞在時間が長い記事の直下に置く、1,980円の業務向け単発商品」だった。仮説としては悪くない。**そして90日経ったいま、それは着手すらされていない。**

封印期間の90日で起きたことを並べる。

| 決定 | 90日後の結果 |
|------|------------|
| Zenn Books = 封印 | **¥1,900の売上**（封印したはずの形式） |
| ブログ単発商品 = 主軸 | ¥0（未着手） |
| note連載 = 死亡と判定 | ¥0（判定は正しかった） |
| アフィリエイト = 降格 | ¥0（判定は正しかった） |

**唯一「やるな」と決めたものだけが金を生んだ。**

### なぜこの間違いが起きたか

原因は分析の質ではない。**何を見ていたか**の問題だった。

顧問団に渡した材料は「プロジェクトの形状」「工数」「過去の完走率」だった。**実際の売上データを渡していなかった。** だから「重くて止まりやすい形式だ」という正しい分析が、「だから売るな」という間違った結論になった。

この失敗の形は、Ch.14の自己改善ループとまったく同じである。

> **持っている証拠を入力に入れないと、分析はどれだけ精密でも間違った方向に収束する。**

エージェントは渡された材料でしか考えない。**AIの判断が間違うとき、たいてい壊れているのはAIではなく入力である。**

そして皮肉なことに、封印を決めた90日はちょうど今日、2026年8月29日で満了する。この改訂版は、封印が解けた日に書かれている。

## 売れた2冊の共通項

n=2なので法則は名乗れない。仮説として書く。

| | 本書 | もう1冊 |
|---|---|---|
| 価格 | ¥1,900 | ¥2,000 |
| 分量 | 12章 → 16章 | 13章 / 85,000字 |
| 無料公開 | 4章 | なし |
| 売れた時期 | 公開2ヶ月後 | 公開直後 |

共通しているのは4点だ。

**① 価格帯が1,900〜2,000円**

これは戦略文書で立てた「業務経費で落とせる帯」という仮説と一致した。500円ではない。**安すぎると、逆に信頼されない**という読みは当たっていたようだ（n=2だが）。

**② タイトルの前半に固有名詞がある**

`Claude Codeで作る〜` `Claude仕事術〜`。検索でもタイムラインでも、最初の数文字で「何の本か」が判別できる。

**③ 知識ではなく作業を代行している**

「〜とは」ではなく「〜で作る」「〜術」。読者が買っているのは情報ではなく、**自分でやると何十時間かかる試行錯誤**のほうだ。

**④ 他人には書けない**

これが本質だと思う。本書は私のVaultの設計図そのものだ。同じ本を書くには、同じシステムを8ヶ月動かすしかない。**機能紹介は誰でも書けるが、240日の運用記録は240日かけないと書けない。**

逆に言えば、③と④を満たさない企画は有料にすべきではない。調べれば書けることは無料で出す。**自分の手元でしか出ない数字だけが、有料の側に立てる。**

## 売れなかったものから学んだこと

### note連載モデルは構造的に死んでいた

「無料記事 → 連載 → 月額サブスク」という4層のファネルを設計していた。6週間運用してフォロワー6人、収益0円。

失敗の原因は熱意でも本数でもなく、**読者の性質を読み違えていた**ことだった。

> 検索から来た読者は「媒体」を信頼しない。**検索の答えを得たら、閉じる。**

彼らは「この人の次の記事も読みたい」ではなく「この問題を今すぐ解決したい」で来ている。フォローという行動が発生する場面が、そもそも導線上に存在しなかった。

**ファネルの各段で、読者の動機が接続しているかを確認していなかった。** これはCh.14で書いた「ファネル最終段を先に測る」とまったく同じ失敗である。私は3ヶ月違いで、同じ穴に2回落ちた。

### X.com: 4,687インプレッション → フォロワー純増0人

30日で35投稿。合計4,687インプレッション。**フォロワーの純増は0人だった。**

数字を分解したら、原因は一意だった。

**他者の投稿への返信が、30日間で0件。**

発信が100%ブロードキャストで、新規の人が私を見つけてフォローを判断する場面自体が発生していなかった。インプレッションは「表示された回数」であって、「誰かが私を認識した回数」ではない。

**リーチと新規到達は別物だ。** 705インプの投稿がプロフィールクリック0件で、75インプの体験談が1件だった事実とも整合する。

ここから主変数を「投稿数・インプレッション」から「**他者の文脈に自分が現れた回数**」に変えた。ただし正直に書くと、**この打ち手はまだ成功していない**。返信も引用投稿も、11日間で採用0件だった。仕組みは作った。実行されていない。

### アフィリエイト: 母数が足りなければ何をしても0

週あたり256PVでは、アフィリエイトは月0〜1件にしかならない。計算すればわかることだった。**計算する前に設置していた。**

## 8ヶ月でわかった、収益化の唯一の完走パターン

複数の試行のうち、**最後まで走り切ったものには共通の形があった**。

> **1日でタイムボックスして出荷 → その過程を記事化 → 記事の末尾に有料リンク**

このパターンだけが完走した。逆に、作り込み型のプロジェクト（数週間かけて完成させてから公開する形）は、**例外なく途中で止まっている**。

理由は明快で、報酬の位置が違うからだ。

| 形 | 最初の報酬まで | 結果 |
|----|------------|------|
| 1日出荷 → 記事化 | **1日** | 完走する |
| 作り込み → 完成後に公開 | 数週間〜数ヶ月 | 必ず止まる |

エージェント組織を持っていても、**人間側の完走率は変わらない**。組織が代行できるのは作業であって、モチベーションの構造ではない。

だから設計を変える。**「意志力が要らない長さ」に企画を切る。** これは仕組みの話ではなく、企画の粒度の話だ。

## 目標を「金額」から「確定した数字」へ置き換えた

当初の目標は「90日で月5万円」だった。達成不能だった。

置き換えた目標はこうなっている。

> **実コンバージョン率を1本だけ確定させ、スケールできるかを数字で判断できる状態にする。**

金額目標には致命的な欠点がある。**達成できなかったとき、何がわかったのかがゼロ**なのだ。「5万円に届かなかった」からは次の一手が出てこない。

一方「この導線のコンバージョン率は0.3%だった」なら、次が決まる。0.3%が十分なら流量を増やす。足りないなら導線を変える。**どちらに転んでも前進する。**

Ch.14で書いた「ファネル最終段を先に測る」と、これは同じことを言っている。**測れていない目標は、達成しても失敗しても学習が起きない。**

## それでも続ける理由

8ヶ月で3,385円。これを見て「割に合わない」と思うのは正しい。時給で考えるなら、この8ヶ月は完全な赤字だ。

それでも私が続けるのは、2つ理由がある。

**ひとつは、買ってくれた人がいるという事実そのものだ。**

2冊とも、私の知らない人が、1,900円と2,000円を払って買っている。無料で読めるものが無限にある2026年に、**わざわざ金を払って読む価値があると判断した人が実在する**。届く相手が少なくても、確かに届いている。この事実は、PVやインプレッションでは代替できない情報だった。

**もうひとつは、資産の性質が違うことだ。**

X.comの投稿は3日で流れる。ブログ記事はSEO順位が落ちれば沈む。しかしこの本は、**8ヶ月動かし続けた記録**であり、時間が経つほど厚くなる。初版は「実運用3ヶ月」だった。この改訂版は「8ヶ月」だ。来年には「1年半」になる。

**期間と到達点を数値で語れる資産は、待つほど強くなる。** 私が持っている数少ない模倣困難な資産は、器用さでも文章力でもなく、**単に長く続けていること**だった。

## アンチパターン3つ

### NG1: 判断材料に実績データを入れずに戦略を決める

私はこれで、唯一の収益源を封印した。**分析の精度を上げる前に、持っている数字を全部入力に入れる。** AIの判断が間違うとき、壊れているのはたいてい入力である。

### NG2: 金額を目標に置く

達成できなかったとき何もわからない。**「1本のコンバージョン率を確定させる」のように、成否どちらでも学習が残る目標にする。**

### NG3: 報酬までが遠い形で企画を切る

作り込み型は例外なく止まった。**1日で出荷できる粒度に切る。** エージェント組織は作業を代行するが、人間の完走率は上げてくれない。

## まとめ

- 8ヶ月・240日の売上は **¥3,385**（Zenn Books 2冊）。他の5チャネルは全部ゼロ
- 最大の判断ミスは、**実績データを入力に入れずに戦略を決め、唯一の収益源を封印した**こと
- 売れた本の共通項は、①1,900〜2,000円 ②タイトル前半に固有名詞 ③知識でなく作業の代行 ④**他人には書けない**
- note連載もX運用も、**ファネル最終段の動機を確認せずに上流を増やした**点で同じ失敗だった
- 完走したのは「**1日で出荷 → 記事化 → 有料リンク**」だけ。エージェント組織は作業を代行するが、人間の完走率は変えない
- 目標は金額ではなく**確定した数字**に置く。測れない目標は成否どちらでも学習が起きない

そして最後に、この本を読んでいるあなたに伝えたいことがある。

**私は、まだ成功していない。**

組織は動いている。無人層も回っている。ルールも積み上がった。それでも稼げてはいない。この本に書いてあるのは「うまくいった方法」ではなく、**8ヶ月動かし続けた人間が、どこで何を間違えたかの全記録**だ。

あなたがこの設計図を使えば、私の8ヶ月を1週間で追い越せる。そして**その先で、私がまだ知らない失敗をする**。もしそこまで行ったら、ぜひその記録を書いてほしい。私が読みたい。

回すことには成功した。稼ぐことはこれからだ。私はまだ、この本の続きを書いている途中にいる。
